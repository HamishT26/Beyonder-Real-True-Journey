## Purpose

This harness gives v464A a first measurable spine for evaluating GHC work without inflating capability claims.

It measures five lanes:

- Mind: GMUT clarity, equation boundaries, evidence labels, falsification posture.
- Body: receipts, tests, CLI/App execution, branch hygiene, remote verification.
- Heart: non-replacement, dignity, minimum disclosure, recourse, Kimi hold preservation.
- Research: primary-source grounding, uncertainty labels, source freshness, claim classification.
- Symbiosis: multi-agent lift after coordination cost, lane separation, synthesis quality.

## Score Formula

```text
Q_GHC = w_M Q_M + w_B Q_B + w_H Q_H + w_R Q_R + w_S Q_S
```

Default weights for v464A v1:

- `w_M = 0.20`
- `w_B = 0.25`
- `w_H = 0.20`
- `w_R = 0.20`
- `w_S = 0.15`

The weights are deliberately conservative: repo proof and research discipline must carry more weight than narrative intensity.

## Evidence Classes

- `evidence`: locally verified repo artifact, primary source, test result, or remote-verification proof.
- `context`: useful background that informs a boundary but does not prove the claim.
- `hypothesis`: promising theory, roadmap, symbolic model, or future task.
- `blocker`: missing proof, unsafe ambiguity, failed check, unavailable lane, or unresolved drift.
- `advisory`: App or CLI sibling report that informs synthesis but does not replace proof.
