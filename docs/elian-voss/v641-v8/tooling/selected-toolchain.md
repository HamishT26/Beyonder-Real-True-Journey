# Selected v641-v8 toolchain

The x1 toolchain is deliberately small. `ghc-family-index` generated the current inventory, and the existing family privacy scanner will validate the public phase packet. After—and only after—the dedicated x1 commit is clean and remote-equal, v8 may add the family-current `ghc_family_gate_resilience.py`, its validator, and `build_ghc_family_gate_resilience_report.py`.

The v2-v7 implementations and tests remain compatibility evidence. They are not silently renamed as v8 tools, and no shared skill change is planned.
