## Procedure

1. Use the current owner main branch across bundles until either tracked or materialized files reaches 2,000. Forecast the whole next tranche before adding it.
2. At the ceiling, preserve a clean pushed head and create a fresh additive branch/worktree. A blank root needs an explicit source-provenance link and must not claim ancestry it does not have.
3. Do not delete old worktrees, reset branches, force push or create a new remote repository as an incidental cleanup step.
