## 09. Five finite models and actual browser evidence

The interactive quadratic laboratory contains five predeclared finite models: bowl, ridge, cap, saddle and flat. Each has twenty-five exact rational table rows, for 125 rows total. Model generation made 135 bounded runtime requests including each minimum and curvature classification. Five deliberately changed model-row subjects remain failed, separately from their passing rejection checks. The model receipt preserves exact expressions and original assumptions.

Twelve actual browser checks passed. Every rendered table value was compared with the selected small-integer polynomial expressions, and the tests exercised model selection, point controls and reset. They checked for layout overflow, runtime console errors, and visible physical-error, authority and Stage 20 boundaries. The temporary browser tab was closed and the exact owned preview server was stopped after checking its identity. No screenshot, image, PDF or other prohibited visual artifact was authored. The HTML itself is the shareable interactive artifact.

The browser checks establish observed behavior on that session's selected surface. Manual visual inspection, assistive-technology evaluation, cognitive review and cultural accessibility review remain open. Loopback request counts were not instrumented, so the packet makes no whole-workflow zero-network claim. Table correctness does not show that the model describes a physical system. Numeric plotting coordinates are a display projection of exact table data, and physical error remains unknown. A successor should preserve the useful browser evidence and the equally important limits together.
