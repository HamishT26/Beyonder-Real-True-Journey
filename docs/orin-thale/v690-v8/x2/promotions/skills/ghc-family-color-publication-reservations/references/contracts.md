# Contract routing reference

Merged operations: metadata_disclosure_minimization, color_review_quorum_gap, publication_authority_gap.

The companion public runner is `ghc_family_color_publication_reservations.txt`. Its standalone intake envelope is intentionally narrower than the owner-phase executors: it validates an allowed operation name, a finite record list and an explicit false authority flag, then returns a deterministic count and refusal envelope. It does not reproduce the Orin phase, confer authority or establish real-world behavior.

All source phase-local skills remain attributable. Consolidation is packaging, not independent validation or new scientific evidence.
