# Contract routing reference

Merged operations: calibration_expiry_state, conversion_workload_budget, profile_rollback_checkpoint.

The companion public runner is `ghc_family_color_calibration_lineage.txt`. Its standalone intake envelope is intentionally narrower than the owner-phase executors: it validates an allowed operation name, a finite record list and an explicit false authority flag, then returns a deterministic count and refusal envelope. It does not reproduce the Orin phase, confer authority or establish real-world behavior.

All source phase-local skills remain attributable. Consolidation is packaging, not independent validation or new scientific evidence.
