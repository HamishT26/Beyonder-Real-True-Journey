Merged operations: color_channel_partition, profile_link_projection, profile_tag_allowlist, profile_revision_lineage.

The companion public runner is `ghc_family_color_profile_integrity.txt`. Its standalone intake envelope is intentionally narrower than the owner-phase executors: it validates an allowed operation name, a finite record list and an explicit false authority flag, then returns a deterministic count and refusal envelope. It does not reproduce the Orin phase, confer authority or establish real-world behavior.

All source phase-local skills remain attributable. Consolidation is packaging, not independent validation or new scientific evidence.
