# v648-v4 source ledger

- **SRC-LIVE-REQUEST** — Hamish current v648-v4 activation and committed Eiren baton (`current`, `live_authority`). Controls solo ownership, no replay, x1-before-x2, four-commit cap, platform exclusions, privacy, and terminal route.
- **SRC-GIT-MAILMAP** — Git mailmap documentation (`current`, `official`). Mailmap changes displayed canonical names and addresses; it is not an identity replacement or commit-object rewrite.
- **SRC-CUTKOSKY** — Singularities and Discontinuities of Feynman Amplitudes (`stable`, `primary_research`). Cut conditions constrain perturbative discontinuities; they are not empirical GMUT observations.
- **SRC-FERMI-DATA** — Fermi Science Support Center Data and Products (`current`, `official`). The 4FGL-DR4 catalog and associated caveats define a possible data surface, not a GMUT likelihood.
- **SRC-FERMI-DR4** — HEASARC Fermi LAT 14-Year Point Source Catalog 4FGL-DR4 (`current`, `official`). Catalog fields, provenance, associations, and release identity require explicit selection and systematic treatment.
- **SRC-OASIS-CAP** — OASIS Common Alerting Protocol 1.2 (`stable`, `official_standard`). CAP supplies structured identifiers, updates, cancellations, language, audience, and warning fields; it does not authorize a real broadcast.
- **SRC-RFC9470** — RFC 9470 OAuth 2.0 Step Up Authentication Challenge Protocol (`stable`, `official_standard`). The protocol defines insufficient_user_authentication, acr_values, and max_age while leaving authentication mechanics and policy outside scope.
- **SRC-RFC9470-ERRATA** — RFC 9470 reported errata (`watch`, `official_status`). A reported example-timestamp erratum is monitored and never silently treated as accepted normative text.
- **SRC-RFC5545** — RFC 5545 iCalendar (`stable`, `official_standard`). Content folding, components, parameters, recurrence, timezones, and attachments require bounded parsing policy.
- **SRC-ICAL-JSCAL-DRAFT** — IETF CALext iCalendar Format Extensions for JSCalendar draft (`draft`, `official_draft`). Extension properties remain work in progress; the bounded parser keeps unknown or draft semantics explicit and unpromoted.
- **SRC-WCAG22** — Web Content Accessibility Guidelines 2.2 (`stable`, `official_standard`). Media alternatives and operability obligations cannot be closed by structural checks alone.
- **SRC-WHATWG-MEDIA** — WHATWG HTML Standard media elements and timed text tracks (`current`, `official_standard`). Track kind, language, labels, captions, descriptions, and media controls provide structural contracts only.
- **SRC-TUR** — Thermodynamic Uncertainty Relation for Biomolecular Processes (`stable`, `primary_research`). Current precision and entropy-production bounds are domain-specific physical results, not measures of psyche or agency.
- **SRC-DID** — Difference-in-Differences with Multiple Time Periods (`stable`, `primary_method`). Staggered treatment timing requires explicit comparison groups and identifying assumptions; a software board is not causal evidence.
- **SRC-NZ-PRIVACY** — New Zealand Privacy Commissioner privacy breach guidance (`current`, `official_authority`). Real harm, notification, privacy, and remedy decisions require competent human authority and affected-person consideration.
- **SRC-TE-MANA-RARAUNGA** — Te Mana Raraunga principles of Māori data sovereignty (`stable`, `primary_authority_source`). Māori data and concepts remain under Māori governance; software confers no Māori authority.
- **SRC-CODEX-CLI** — OpenAI Codex CLI stable package channel (`watch`, `official_package`). Version status may be observed, but this phase does not update the desktop application.
