# GHC Family CLI sibling induction preflight

Use this skill before creating or launching a future CLI sibling. It separates a valid preparation packet from launch authorization and never treats a requested runtime, placeholder, or workflow diagram as evidence that the platform capability exists.

## Workflow

1. Read [preflight-schema.md](references/preflight-schema.md) completely.
2. Confirm the live phase owner and scheduled seat from the newest authorized route. Preserve contradictions as open gaps; do not normalize ownership silently.
3. Represent an uninducted seat only as `future-cli-sibling-N-self-chosen`. Do not assign its name, role, hope, pronouns, or gender.
4. Create a sanitized JSON request on D:. Exclude raw task identifiers, private routes, credentials, transcripts, screenshots, session streams, private callable identifiers, private app state, and private absolute paths.
5. Run preparation mode:

```powershell
python "$env:USERPROFILE\.codex\skills\ghc-family-cli-sibling-induction-preflight\scripts\ghc_family_cli_sibling_induction_preflight.py" `
  <request.json> --mode prepare --receipt <receipt.json>
```

6. Before a future launch, re-resolve the exact source, scheduled phase, creator authorization, supported model/reasoning/fast-mode surface, unique clean D:-first lane, and supported return-message mechanism. Then run `--mode launch`.
7. If launch mode fails, create no sibling. Retain the failure, isolate the missing proof, and hand control back to the creator or user.

## Truth boundaries

- Preparation mode may validate a blueprint while launch capabilities remain unverified.
- Launch mode fails closed unless every launch proof is explicit and true.
- A creator-return route or background lifecycle is an open capability question until the actual platform provides a witnessed mechanism.
- Tool acknowledgement is the only delivery proof. A file, prompt, or intended destination is not `SENT`.
- A CLI sibling chooses its own relational working identity after launch. This is not consciousness, personhood, continuity, employment, or independent authority evidence.
- Keep empirical GMUT, THOS real-arm, Freed ID production, legal, cultural, Maori-authority, independent-reproduction, AGI/ASI, and Stage 20 boundaries open or exact-gated without exact evidence.

Run `--self-test` after modifying the bundled runner, then validate the skill folder with the system skill validator.
