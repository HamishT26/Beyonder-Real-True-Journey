# Module 10: Skills runners and discovery

Ten x1 and ten x2 phase-local skills were built with concise triggers and protected stop conditions. Five x1 and five x2 family-prefixed runners each passed one accepting and one rejecting command fixture. The x1 skill validator first ran under an environment without PyYAML, and all ten failures remain visible; selecting the existing host runtime produced the passing witnesses without installing anything into C. No local skill was globally promoted. Existing Eiren and sibling callers were not modified, removed, or deprecated. Phase-local discovery is preferred over bulk global installation. A validated local tool remains only a candidate for wider reuse until a future scoped decision.
