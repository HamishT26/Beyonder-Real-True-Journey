# v642-v2 selected toolchain

`ghc-family-index` produced the phase-local inventory. The selected surface is deliberately small: the family privacy scanner, the sealed v642-v1 boundary tools for source replay, and four additive `ghc_family_*` or `build_ghc_family_*` tools planned for x2.

At x1, those four new tools are names only and have not been implemented. This keeps the x1 commit free of x2 code and outcomes. Existing source tools remain byte-stable compatibility evidence.
