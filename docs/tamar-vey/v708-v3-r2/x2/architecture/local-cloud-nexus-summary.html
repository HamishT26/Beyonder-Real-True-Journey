Local/Cloud Nexus — bounded architecture summary

This is a static, same-owner design report. It is not a deployed operating system, an autonomous agent router, independent reproduction, or authority.

Data path

  1. Local owner lane freezes a source commit and normalized manifest.
  2. A sanitized capsule binds expected source, manifest, and payload digests.
  3. The cloud runtime performs bounded checks on the capsule only.
  4. Returned artifacts enter local quarantine and require explicit review.
  5. No cloud result automatically merges, publishes, routes, or grants authority.

Truth separation

Layer What can be established What does not follow
Source Expected commit and manifest Correctness of source claims
Environment Requested and observed fields Unobserved network or privilege state
Delivery A send was accepted and acknowledged Recipient completion
Repository Bounded owner artifacts and tests Production or independent validation
