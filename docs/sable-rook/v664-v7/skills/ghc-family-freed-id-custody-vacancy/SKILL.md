# GHC Family Freed ID Custody Vacancy

Use this skill for synthetic claim envelopes containing only surrogate object and batch tokens, a digest placeholder, revision, challenge, and explicit role vacancies.

Reject a real identifier, key, proof, issuer, subject, resolver, status service, revocation event, interoperability claim, or trust decision. Require nonproduction status, minimization, challenge, cancellation, recovery vacancy, and authority reservation.

Passing is structural representation only. Production identity still requires standards-conformant keys and proofs, live services, interoperability, privacy and independent security review, recovery evidence, trust governance, and affected-party oversight.
