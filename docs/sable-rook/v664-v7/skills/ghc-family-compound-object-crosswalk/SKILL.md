# GHC Family Compound Object Crosswalk

Use this skill for synthetic compound-object mappings among structural sections, preservation objects and events, and presentation canvases or ranges.

Require an explicit source field, target field, cardinality, loss note, vacancy status, extension policy, and refusal state for every mapping. Reject missing cardinality, silent loss, fabricated agent or event, unknown extension acceptance, or a conformance or interoperability conclusion.

Return a field-level receipt. A structurally complete crosswalk is still not a valid METS, PREMIS, or IIIF implementation and is not production interoperability evidence.
