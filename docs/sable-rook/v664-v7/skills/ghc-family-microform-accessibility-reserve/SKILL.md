# GHC Family Microform Accessibility Reserve

Use this skill for static reports with frame sequences, image placeholders, OCR uncertainty, tables, alternatives, and status messages.

Require semantic landmarks, descriptive headings, table captions and headers, text-only sequence alternatives, uncertainty notices, visible focus declarations, static print fallback, and explicit manual-review reservations. Reject unlabeled tables, image-only meaning, hidden uncertainty, autoplay, keyboard traps, or complete-conformance language.

Passing is a structural check, not complete WCAG conformance or evidence from browsers, assistive technologies, Maori-language reviewers, or affected users.
