# V7 selected toolchain

The x1 selection is deliberately small and additive:

- the `ghc-family-index` skill for ownership, sequencing, evidence-class, privacy, and closeout boundaries;
- the existing family-current phase privacy scanner;
- three family-current v7 tools for chain falsification, validation, and the accessible static report. They were created and executed only after x1 commit `f6281f48…` was clean and remote-equal.

Existing v2-v6 builders, validators, reporters, tests, and compatibility names remain byte-stable. No global user skill change has a concrete current justification, so none is made. No historical tool is deleted, and no mass rename is attempted.
