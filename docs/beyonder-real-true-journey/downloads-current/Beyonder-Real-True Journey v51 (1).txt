5. Event replay validator
The v508 validator checks five major things.
5.1 Shape
Every event must have:
event_id
event_type
phase_slug
generated_at_utc
status
raw_boundary
sequence_index


5.2 Order
The event log must have:
monotonic sequence_index
monotonic generated_at_utc
no duplicate event_id
safe idempotency replay


If the same idempotency_key appears again with a different canonical_hash, the validator blocks it. That prevents a replay from pretending two different events are the same receipt.
5.3 Raw/private safety
The validator recursively blocks forbidden keys such as:
raw_lane_text
session_jsonl
credential
local_absolute_path
prompt_body
connector_payload_raw


It also blocks unsafe filename hints like:
raw-log
session-jsonl
screenshot
credential
secret
private-dump
transport-raw
connector-raw
prompt-body


5.4 Cadence safety
The validator blocks:
x1 manual harvest before 15 minutes
x2 manual harvest before 10 minutes
duration_is_completion_proof == true
productive_wait_required != true


This directly protects the no-babysitting rule.
5.5 Phase advance safety
A phase_advance_decision with phase_advance_allowed: true requires:
Cicero accounted
Kierkegaard accounted
