# Finite support-coalition domain

Each synthetic rule declares one to six labeled components, nonnegative integer weights and costs, and a positive quota no larger than the total weight. A coalition wins exactly when its declared weight reaches the quota. Component zero is the least significant coalition-mask bit, and masks are listed in ascending order. All thirty main profiles use five components and have distinct complete Boolean outcome tables. They are not claimed to be thirty nonisomorphic games.

The new domain extends source-provenance work with minimal supporting sets, pivotality conventions, blocking sets, cost frontiers and counterexamples. Raw swing counts enumerate winning coalitions whose result changes when a specified component is removed. Normalized swing shares divide those counts by their total. Shapley–Shubik shares use the declared uniform-permutation convention. The Python expectation builder enumerates permutations, while the Node implementation uses the subset-factorial formula. Both are same-owner calculations under shared infrastructure.

The CWI author-hosted Simple games chapter supplied finite definitions and a discriminating example. Shapley's RAND publication record supplied bibliographic context only; its scanned PDF text was not extracted and receives no content credit. For the synthetic rule [3; 2,1,1], normalized swing shares and permutation-pivotal shares differ. Nothing in these calculations measures an actual person's influence, fairness, consent or competence. Costs are model inputs, not prices, risk probabilities or real resource measurements.
