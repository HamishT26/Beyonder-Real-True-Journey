# GHC Family Main Capability Router

Use this common entry point to find installed mathematical, evidence, workflow, platform and human-governance capabilities. The catalogue includes every direct installed skill with a SKILL.md at its recorded snapshot. Classification may overlap; matching words do not establish equivalent implementations.

Invoke runner.txt with a request JSON file and a new output JSON file. A query request has {"query":"exact words or skill name","limit":10}; limit is one through fifty. The runner returns matching source paths, hashes and discovery groups. It never imports a discovered runner, launches a process, reads credentials, changes a model or contacts a task.

For an actual use, read the selected current skill, verify its source hash and its dependencies, resolve the public caller contract, then apply the user's current authority. Preserve original names and wrappers. Keep an implementation merger as a review candidate until semantics, callers, license, dependencies and rollback are established. Five separately tested robust-decision groups are available alongside this hub; their accepting and rejecting smokes do not validate the entire inherited inventory.

Restore the prior immutable catalogue to roll back discovery. Never delete another skill to reconcile a lexical overlap. Current source, exact final, canonical, installation, delivery and recipient completion remain separate facts.
