# D-first structured evidence toolchain

Use this skill only for an explicitly authorized owner phase. It coordinates existing responsibilities; it does not erase or supersede their source skills.

1. Apply `ghc-drive-bank-guardian` before creating an environment. Require a literal, owner-attributed D:-drive root and a rollback token. Never mutate system Python, the npm global prefix, profiles, PATH, plugin caches, host security, Windows features, or the Codex desktop application.
2. Apply `ghc-family-meta-tool-box` to check the current direct-tool catalogue and refuse filler or silent reinstallation credit. Registry discovery is not installation authority.
3. Freeze exact direct versions, official registry provenance, Python wheel SHA-256 values, Node lock integrities, expected transitive dependencies, useful smokes, rejecting witnesses, rollback, and protected gates before installation.
4. Prefer a new isolated Python environment with wheel-only, hash-required installation and a separate private Node project with exact versions and lifecycle scripts disabled. Preserve the package lock and artifact inventory.
5. Give every direct surface one bounded positive smoke and one rejecting or boundary witness. A successful import, format, query, or schema check is same-owner local software evidence only.
6. Apply `ghc-family-method-flow-state` to retain every resolver, parser, audit, smoke, or wrapper failure at zero credit. Recover only the failed dependency; never rewrite a failed aggregate as a pass.
7. For global skill promotion, fail on any existing destination, write only the authorized skill directory, validate the skill, exercise accepting and rejecting fixtures, and prove source/global byte parity. Never overwrite a different skill.
8. Apply `ghc-freed-id-flashcards` to project the owner, pillar, bounded practice, and task/method tiers. Omit or redact private identifiers and keep file-backed evidence as the source of truth.
9. Run one bounded advisory audit per corrected environment. A zero-finding snapshot is not exhaustive security, future safety, legal license interpretation, professional certification, production readiness, or independent review.
10. Roll back only the exact environment or collision-free skill paths named by the transaction token, after literal-path verification. Preserve receipts and failure witnesses before rollback.

Keep `completed`, `represented`, `open_gap`, and `exact_gate` as the only core outcomes. Preserve empirical, participant, professional, production, legal, cultural, Maori-authority, privacy-complete, accessibility-complete, exhaustive-security, independent-reproduction, AGI/ASI, consciousness/personhood, Theory-of-Everything, and Stage 20 gates.
