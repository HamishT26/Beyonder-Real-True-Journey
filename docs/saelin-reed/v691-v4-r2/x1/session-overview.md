## Discovery and control

The registry evaluator uses exact title and endpoint kind, counts unique synthetic keys and keeps incomplete pagination distinct from absence. A record repeated with the same key does not create a second identity; a second distinct key does. Archived-only and conflicting current/archive records have explicit outcomes. This distinction addresses the real task-service problem without assuming that a title search proves delivery.

The control evaluator selects only user-origin messages for the requested phase. Later document text cannot override a current pause. Same-sequence conflicts remain holds, and a newer expired control does not silently revive an older authorization. History coverage requires complete pages, matching item count and a public user message. An empty paginated response therefore remains unknown.

## Recovery, budget and persistence

The recovery planner spends a declared duration on each attempt and a capped exponential delay between attempts. Ready, pause, redirect, acceptance and unresolved submission outcomes stop it for different reasons. The tool does not contact a task. It returns a plan that can be inspected, while the actual terminal handoff will use current native evidence.

The receipt reducer accepts preparation, one submission and one terminal outcome. A second submission after acknowledgement or timeout is invalid. The append-only chain binds payload, order and predecessor digest and reports its verified prefix on tampering. These are complementary checks: a hash confirms local bytes, while a receipt state describes a claimed transition. Neither alone proves external delivery.

The budget evaluator distinguishes spent, reserved and available integer cents. It rejects duplicate reservations and over-capacity spending. A Map handles a prototype-shaped reservation key without corrupting object state. Resource transfers check stock and destination capacity first; accepted transfers have zero total residual. Clock windows that straddle expiry retain uncertainty.
