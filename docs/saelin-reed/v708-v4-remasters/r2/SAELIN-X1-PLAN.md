# Saelin P02 x1 finite dynamics

This contribution explores fifteen distinct mathematical structures using small, deterministic local computations. It does not propose fifteen new physical laws or validate GMUT. State trajectories have three or more coordinates and an explicit time coordinate; a later viewer may display a 3D projection with time as its fourth control.

The plan uses 200 RK4 steps over four dimensionless time units, followed by a 400-step numerical comparison. That comparison is same-owner consistency evidence. Each model has an explicit equation, state shape, project mapping, and invariant or bound. Negative contract checks cover malformed requests and nonfinite derivatives. A driven model retains a counterexample to treating an externally driven subsystem as energetically closed.

The fifteen families are affine null geodesics, linear Hamiltonian flow, nonlinear Hamiltonian flow, dissipation, external driving, antisymmetric velocity coupling, inverse-square central force, graph diffusion, a discrete hyperbolic field, nonlinear gradient flow, probability transport, bounded population flow, frequency-dependent games, nonlinear reaction kinetics, and constrained manifold dynamics. They use synthetic dimensionless inputs, not experimental observations.

Eight learning disciplines: applied mathematics, theoretical physics, numerical analysis, mechanical engineering, chemical kinetics, control engineering, statistics, and research ethics. Four next recommendations: geometric integration, inverse problems, metrology, and accessible scientific visualization. These describe study activity, not professional qualifications.
