Reading the result

Every variable ranges from −2 to 2. A bound [u, v, w] means t[v] − t[u] ≤ w. Additional bounds remove incompatible assignments. Some networks have no feasible point: their negative cycle records the contradiction.

The green points come from saved, verified phase results. Projection and reference changes were checked separately. A view rotation is only a display change.
