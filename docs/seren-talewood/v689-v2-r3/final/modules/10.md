Thirteen new direct packages were installed in the isolated shared D-drive capacity environment. The final closure contains sixteen distributions and 401 installed files. Hash and size checks matched the reviewed registry artifacts. Each wheel had a bundled license record, and 351 unchanged wheel payload members were compared with their installed locations. This is a provenance and bounded validation record, not legal advice or exhaustive security certification.

The initial DiskCache choice was rejected before installation after a published unsafe-pickle advisory was found. Its wheel, metadata and review remain retained and uninstalled. An additive amendment selected Zict 3.0.0 for explicit JSON-byte storage without a pickle codec. The package count remains thirteen direct additions; the rejected candidate is not counted as an installation. The source plan is preserved rather than silently rewritten to make the later choice look original.

All thirteen direct packages were exercised by twenty-six bounded API checks. The system interpreter was not upgraded, source builds were not run, and generated package launchers were not invoked. The installed CLI still matches stable metadata at 0.153.4. The D npm prefix and the user-managed desktop app were preserved. Select from the broader inherited tool bank when a dependency fits the work; availability is not a reason to execute every installed package.

One collector initially treated a wheel archive path as its literal installed path. Pip correctly relocates a RapidJSON runtime DLL from the wheel's data/platlib section to the target root. The failed collector and its result were retained. An isolated byte comparison confirmed the relocated DLL, then the corrected snapshot covered every payload member. The package API checks were not replayed to repair that mapping.

The method ledger now contains twenty-nine methods, 297 retained failed witnesses and 637 passing witnesses. The failed witnesses include designed malformed subjects as well as operational failure groups. They are not 297 failed scientific discoveries or host crashes. A separate backlink defect caused 296 schema issues from one omitted relationship rule. Failed subjects, as well as passing checks, must appear in their method's witness list. The original ledger and rejection receipt remain bound, and the correction was validated without rerunning the model experiments.
