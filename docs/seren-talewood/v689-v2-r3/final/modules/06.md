For every case in this module, compare the complete typed result and preserve the original input. An accepted model result is not a real-world observation; a correct refusal gives no success credit to its malformed subject.

These groups connect dependency constraints and resource accounting. The dependency graph must be acyclic and contain every referenced vertex. The token ledger separates cached input from uncached input and output, but it uses caller-supplied rates rather than a verified bill. Context batching charges the stable prefix to every batch, preserves order and refuses an oversize indivisible module. Coverage clips observations to the declared window and reports uncovered intervals. Allocation retains the tie policy and does not decide rights.

The additional invariant tests make some hidden assumptions visible. Queue service and waiting are conserved in the declared timeline. Every packed item occurs exactly once. The sum of charged context costs includes one prefix for each generated batch. Covered and uncovered durations sum to the observation window. A largest-remainder allocation reproduces a known nonmonotonicity when the total number of slots increases. These checks are useful guards for engineering choices; they do not establish independent scientific or governance authority.
