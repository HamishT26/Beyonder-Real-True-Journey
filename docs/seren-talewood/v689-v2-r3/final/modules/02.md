Relative resource savings require an assumption about matched work. Let a Sol run have cost one and an otherwise matched Astra run have cost r. The older average is (1+r)/2 and the new average is (2+r)/3. The fractional saving is (r-1)/(3(r+1)). For r equal to two, three and four, the savings are one ninth, one sixth and one fifth. These scenarios make Hamish's observation usable for planning without pretending it is a measured bill. They do not control cache behavior, output length, model settings, reasoning effort or result quality.
