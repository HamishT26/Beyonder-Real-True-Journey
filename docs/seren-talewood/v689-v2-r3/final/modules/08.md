# Module 08 X2 consent review retry projection and comparison contracts

For every case in this module, compare the complete typed result and preserve the original input. Each corresponding candidate adds an undeclared execute field and must be refused with E_FIELDS before operation evaluation. An accepted model result is not a real-world observation; a correct refusal gives no success credit to its malformed subject.

The remaining groups connect model outputs with explicit use conditions. The consent join checks the subject, declared purpose, expiry and revocation fields but always denies that it verified real consent. The appeal model exposes missing or conflicted reviewers while denying that the resulting roster establishes legitimacy. The retry model calculates finite exposure; it does not submit, resubmit or schedule a real action. Typed path projection preserves a present null value and rejects missing paths without evaluating expressions or expanding wildcards.

The matched-resource comparator requires the caller to establish the same workload and results. If that condition is false, it reports no ratio or saving. A favorable cost measurement is not useful if a different task was performed or its result quality changed. Keep units, sampling method, source bytes and scope with any future comparison. The included local benchmark concerns repeated JSON decoding from an existing byte buffer and is intentionally much narrower than a claim about model performance.
