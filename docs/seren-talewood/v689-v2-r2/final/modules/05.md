## Module 05: X1 workflow contracts and their complete outputs

This module contains the one hundred frozen x1 contracts and their observed complete output envelopes. Each input was defined in the planning root. A matched rejection is a completed validation task while the invalid subject retains zero original success credit. Comparisons preserve JSON types, so a Boolean is not silently accepted as an integer and a floating-point number is not an exact rational representation. Read the operation explanation before extending the domain.
