# Semantic profile for the Seren remaster

The forty operations answer two connected questions: how to make the authorized workflow explicit and inspectable, and how to test limited mathematical and governance claims without enlarging their meaning. The 200 records are distinct finite contracts across these operations. They are not 200 new algorithms, laws of nature, or independently validated discoveries.

## Lifecycle and meaning of a result

This planning definition precedes both execution sessions. One hundred workflow contracts belong to x1. One hundred model and governance contracts belong to x2. Each result is a complete object containing `ok`, `value`, and `error`. A refusal has `ok: false`, a null value, and an explicit error code. A planned refusal can be successfully tested while its invalid input remains a failed subject with zero original success credit.

Both x1 and x2 receive 100 frozen safe contract tasks and twenty reserved places for spontaneous safe work. A reserved place is not an executed task. It is replaced in a separate prospective supplement by an exact task definition before that task runs. Candidate work consists of 100 x2 field-closure challenges to the x1 interfaces. It has no additional proposal novelty credit. The 200 CLEAN/FIX/REFINE tasks produce normalized, source-bound reuse records from the 200 selected inherited proposals; they do not change their source files or execute historical suites.

The fifty exact packets name concrete user-authorized work: thirteen package installations, twenty skill promotions, ten runner promotions, six shared workflow integrations, and the single Eiren activation. Installation and promotion need their declared validation evidence. The Eiren action additionally needs the exact terminal gate and a native available route. Thirty separately represented blocked subjects concern missing evidence, prohibited claims, unspecified destructive targets, or actions outside the requested owner scope.

## Input and resource contract

Inputs use strict UTF-8 JSON. Duplicate keys, nonfinite JSON values, unknown operation fields, malformed nested record shapes, and booleans used as numbers are refused. The operation list fixes the required root fields; there are no silent defaults. Expected error codes are `schema`, `type`, `shape`, `domain`, `duplicate`, `missing`, `sequence`, `conflict`, `path`, `tier`, and `non_unique`.

General collections have a maximum of 500 entries unless a tighter operation limit applies. Deck validation permits at most 2,000 cards because that is also the hard owner file ceiling. Probability matrices have one through eight states. Rational inputs are integers or bounded numerator/denominator strings, with absolute numerator and positive denominator at most one billion. Floating-point JSON values are not silently converted to exact probabilities. Phase projections contain at most 500 assignments. Ordinary arithmetic requests cannot allocate an unbounded list or create a process, file, credential, or network action.

Paths in the workflow operations are portable record strings. Absolute paths, empty segments, backslashes, drive syntax, dot and parent segments, and control characters are refused before segment-aware scope comparison. Matching a record path is not permission to access a real filesystem target.

The Egyptian-fraction search accepts an integer n from two through one thousand, a denominator ceiling no greater than one million, and a pair-iteration budget no greater than one hundred thousand. A budget-exhausted result differs from complete search of the specified finite denominator range. Neither result proves the universal conjecture.

## Probability and entropy assumptions

The model uses finite, discrete-time, row-stochastic kernels. A probability row p advances as pP. Stationarity means pi P equals pi and the entries of pi sum to one. The stationary solver returns an exact rational vector only when the normalized linear system has a unique solution. A reducible family with multiple stationary vectors is refused rather than silently assigned one member.

Detailed balance compares pi_i P_ij with pi_j P_ji after stationarity is checked. Reversal requires positive stationary weights and uses P_rev_ij = pi_j P_ji / pi_i. The current matrix is pi_i P_ij minus pi_j P_ji. These are mathematical properties of the declared kernel. A reversible toy kernel does not establish physical equilibrium, causality, mental continuity, or ethical legitimacy.

Shannon entropy and relative entropy use natural logarithms. Their output strings have twelve decimal places to make the finite readback deterministic; those digits are not empirical precision. The convention zero log zero equals zero is applied by omitting zero-weight terms. A positive numerator with zero reference support is explicitly infinite and has a null numeric value plus the mismatched support indices.

Model entropy production is the relative entropy between the stationary one-step forward flow pi_i P_ij and its reversed flow pi_j P_ji. It is reported in nats per model step. Connecting it to physical heat or thermodynamic entropy requires an observation model, relevant reservoirs, time scales, and physical assumptions such as local detailed balance. None is supplied by these synthetic fixtures. No quantity here is a measure of a person's mind, consciousness, worth, or rights.

Coarse graining aggregates stationary flows over an explicit partition. It reports a projected kernel and separately checks strong lumpability by comparing block-transition probabilities for every state in the same block. When lumpability is false, the projected kernel is not presented as a generally closed description of the original dynamics.

First-hit probabilities treat the declared target set as stopping states, regardless of their original outgoing transitions. A closed class that cannot reach any target retains zero target probability. Hitting times are finite only for states whose probability of reaching the target is one. A positive probability of permanent escape produces a null infinite-time marker.

Total variation is half the L1 distance. The coupling comparison reports this minimum possible disagreement and the disagreement of the separately declared independent product coupling. A comparison of two mathematical constructions is not independent reproduction by another team.

## Governance and evidence assumptions

Risk scores are products of declared ordinal likelihood and impact values on the local one-through-five scale. This is a transparent prioritization convention; it is not a calibrated probability, an expected loss, or a rule required by NIST. Original evidence labels remain attached to every score.

The consent operation compares only synthetic action, resource, purpose, revocation, and expiry fields. Even a complete match returns `authority_granted: false`. A Boolean supplied by the same model cannot establish a real person's consent. The remedy queue orders synthetic records and explicitly records zero decisions taken. Review coverage compares declared required areas with completed record labels; it does not verify that human or assistive-technology review occurred.

Working hypotheses about a future connection between information, physical dynamics, cognition, and governance remain hypotheses. Probability normalization and divergence inequalities are established mathematical properties under their assumptions, not newly discovered fundamental laws of Thermo/Psyche Dynamics. Proposed universal claims that do not supply a measurable mapping or falsifiable prediction remain open. Failures and counterexamples may reduce a claim's strength; an evidence ledger must permit that correction.

The GMUT scalar-tensor/EFT family remains unconfirmed. No new physical likelihood, empirical parameter constraint, quantum completion, or Theory of Everything is claimed. THOS improvements concern this workflow and bounded tools.
