# 05 — Mathematical conventions and comparison

A filtration is part of the input, not a fact inferred from a shape. A face must exist before or at the same parameter value as its coface. Equal parameter values are permitted. Sorting by dimension within a tie gives a boundary-compatible total order without pretending that tied events were measured at different physical times.

The coefficient field is fixed to GF(2). Addition of a boundary row is exclusive-or, so orientation signs disappear in this field. This choice is a mathematical convention and does not assert that coefficients over the integers or another field give the same answer. Torsion and integral homology are outside the implementation.

The boundary of a boundary must be zero. This algebraic identity is checked on every declared column. A failure indicates an implementation or input-closure problem; it cannot be repaired by interpreting the residual as a new physical force. The finite calculation has no spacetime, units, action functional or measurement operator attached to it.

Column reduction maintains D times V equals R, where V records column additions and R is reduced. Nonzero reduced columns have distinct highest occupied rows. A pivot pairs the birth of a class with the simplex that kills it. A zero column creates a class that is either paired later or remains essential within the supplied finite filtration.

Reported intervals include birth and exclude death. Null death means that no death was seen before the supplied filtration ends. It does not mean a physical quantity lasts forever. Equal birth and death are retained as zero-length pairs in a separate operation and do not contribute to a living homology class at a threshold.

For thresholds a no greater than b, the persistent rank is the dimension of the image of H_p(K_a) in H_p(K_b). The core computes the dimension of Z_p(K_a) plus B_p(K_b), minus the dimension of B_p(K_b), with both spaces embedded in common chain coordinates. This follows from taking the quotient by the target boundary space.

The separate oracle does not use pivot reduction. On each tiny fixture it enumerates all source chain vectors whose boundary vanishes, enumerates the span of target boundaries, and groups cycles into cosets. The logarithm base two of the number of distinct cosets is the rank. Exponential enumeration is deliberately restricted to the tiny examples.

The ordinary Betti number at one threshold is a diagonal slice of the persistent rank invariant. It can lose information about which class survives from one threshold to another. The retained counterexample uses intervals [0,2) and [1,3), compared with [0,3) and [1,2). Their pointwise dimensions match, but the image rank from zero to two differs.

Positive scaling and uniform shifting change the labels on a filtration while preserving its order. Vertex relabeling changes names through an explicit bijection. Reversing the tie order can change which concrete simplex represents a class, while the interval multiset remains the comparison object. Equality of barcodes does not assert equality of all input data.

Input refinement retains the original JSON request. The normalized request sorts simplex and vertex presentation, preserving numerical births and the represented complex. Array order changes intentionally. The complete typed operation output is compared before and after normalization. The correction record prevents this semantic preservation from being mislabeled as unchanged typed input.

The synthetic filling-time example changes the triangle face from threshold five to threshold eight. Its one-dimensional interval changes from [3,5) to [3,8). This illustrates dependence on the declared filtration. It supplies no empirical law relating a threshold to physical time, consciousness, ethical value, benefit, or legitimacy.

The reporting layer preserves represented, open-gap and exact-gate outcomes. An accessible text table may be useful before it is tested with assistive technology; the represented result does not count as a completed accessibility evaluation. A correctly returned authority reservation does not perform or authorize a public decision.

The external references in plan/research-sources.json and this overview describe established mathematics or documented API conventions. Their publication does not endorse this implementation. The separate oracle is deliberately small and exponential. For larger inputs, select an appropriate reviewed algorithm and establish its resource bounds rather than silently applying the tiny-fixture oracle.
