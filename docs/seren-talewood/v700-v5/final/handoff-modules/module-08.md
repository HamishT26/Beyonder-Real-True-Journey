## 08. Five simulations and actual browser evidence

The five finite simulations use profiles BC-04, BC-06, BC-12, BC-24 and BC-30. Their lengths are three, four, five, seven and eight; together they enumerate 440 received words. Each row records received-word weight, syndrome index and nearest-codeword distance as three declared coordinates, along with the number of nearest answers. The HTML view projects those coordinates and supplies an exact table. This is a finite combinatorial simulation, not physical geometry or a measured communication experiment.

Actual browser checks covered document structure, language, the skip link, model controls, exact table headers, viewport containment, model changes, a tied answer, invalid-index feedback, reset state and keyboard activation. The first browser-open attempt timed out and left a blank tab; a supported inventory and exact-tab recovery succeeded. Keyboard model selection then revealed a focus defect: replacing the controls moved focus to the document body. The repair focuses the corresponding newly rendered button. An isolated check confirmed keyboard focus remained on BC-24, and reset restored BC-04.

One attempted heading locator used an unsupported option and matched six headings. The exact supported heading name resolved that wrapper failure. All three operational failures remain recorded. The original HTML bytes are retained beside the corrected artifact. Browser checks did not include a human assistive-technology study, cognitive accessibility assessment, affected-user evaluation or independent audit. Do not promote a small successful interface check into complete accessibility or production readiness.
