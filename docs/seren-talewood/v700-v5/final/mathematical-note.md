# Finite binary-code identities and their evidential domain

For a binary linear code C contained in {0,1}^n, define its dual as the vectors v whose dot product with every u in C is zero modulo two. A systematic generator [I | P] has the parity-check matrix [P-transpose | I] because addition and subtraction coincide over GF(2). The runner checks the resulting finite kernel explicitly.

Let A_i count words in C of weight i. The binary MacWilliams coefficient is B_l = (1/|C|) sum_i A_i sum_j (-1)^j binomial(i,j) binomial(n-i,l-j), with an out-of-range binomial coefficient taken as zero. The implementation uses only integers and refuses a nonintegral coefficient. A second implementation multiplies coefficient arrays for (x+y)^(n-i)(x-y)^i and divides by |C|. Direct enumeration supplies a third mathematical representation of the dual distribution.

The underlying finite character sum is S(v) = sum_(u in C) (-1)^(u dot v). If v is in the dual, every summand is one and S(v)=|C|. Otherwise choose a codeword a with a dot v = 1. Pair each u with u+a; the two summands have opposite signs, so S(v)=0. Inserting that indicator into the weight-generating sum and collecting coefficients gives the transform. This is an argument about a declared finite algebraic structure, not an empirical law of a physical channel.

The minimum-distance guarantee also has a bounded hypothesis. If 2t < d, two distinct codewords cannot both be within distance t of the same received word, because their distance would be at most 2t. Outside that radius a nearest answer can be tied or wrong relative to an unknown original message. An arbitrary tie-break is not evidence of successful recovery. The interface retains ties and exposes the number of nearest answers.

Puncturing deletes a coordinate from all words. Shortening restricts that coordinate to zero first. Erasure recovery is governed by the kernel of the restriction to known coordinates: a consistent completion is unique exactly when that kernel has no nonzero word. The additional implementation check compares actual completions with an explicitly enumerated kernel. An algebraic identity alone would not catch a defect in the runner that reports those completions.

These facts inform software contracts and possible experiments. A proposed physical application still requires measured signals, a channel model, calibration, sampling, error estimates and independent review. The synthetic collection-transcription analogy supplies none of those prerequisites. It also supplies no professional authority, identity proof, legal conclusion, cultural mandate or Stage 20 readiness.
