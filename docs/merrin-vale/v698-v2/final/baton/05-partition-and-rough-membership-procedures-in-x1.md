# 05 — Partition and rough-membership procedures in x1

X1 covers typed profiles, the refinement relation, common refinement, least common coarsening, partial block maps, lower approximation, upper approximation, rough boundary, distinguished pairs and uniform choices. A partition is represented by declared labels on a finite state set. Normalization names cells by first occurrence, while members remain in increasing state-index order. Refinement means that every pair identified by the finer left observation is also identified by the right observation. A failed refinement returns an explicit splitting pair rather than silently guessing a block map.

Common refinement intersects two equivalence relations by paired labels. Common coarsening requires transitive closure; unioning the input pairs without closure would be wrong. The production union-find result is compared with the independent exhaustive-partition specification. For a supplied target set, lower approximation takes whole cells contained in the target, upper approximation takes cells that meet it, and boundary is upper minus lower. Empty targets, complete universes and ambiguous cells remain distinct cases. An upper approximation means formal possibility under this partition, not a probability or measured confidence.

Uniform choices intersect the supplied action-label sets across every state inside an observation cell. Each state may have an available action while their shared cell has no common action. This finite counterexample does not establish a safe real controller or model human psychology. All x1 accepting results and refusals matched on the first production execution. Its later word-cap recovery changed only ledger serialization, preserving the complete payload and every successful observation.
