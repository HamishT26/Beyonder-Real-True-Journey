# Certain membership under declared observations

Return the union of complete observation cells contained in the target set.

Use this guide when an explicit finite state set, observation labels and the operation-specific data are supplied. This operation is or_lower. The exact request, complete response, status, caller and literal support-module dependencies are in contract.json. Read that contract before applying the caller. The paired caller admits exactly its two named operations.

From this guide directory, run Node with ../../runners/ghc_family_observation_pair_3.txt and provide one JSON request on standard input or through an explicit file argument. Keep object fields closed. The supported state range is two through six; horizon is zero through four. Targets and transitions are ordered unique state-index sets; transitions are nonempty. The supplied costs are positive integer model units, never money. The path labels refer to normalized left cells and do not identify real people or sensors.

The accepting example and its expected full envelope are stored separately from the malformed example. The malformed example adds one detached annotation and must return closed_fields with status two and external_credit false. A passing refusal does not make that subject successful. Retain the original request before changing a detached copy.

Important distinction for this operation: Return the union of complete observation cells contained in the target set. Exact finite values describe only the supplied record. They do not measure observations, establish psychology or consciousness, certify privacy or safety, allocate rights, supply Maori authority or complete independent review.
