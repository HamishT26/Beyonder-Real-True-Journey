## Exact mathematical result

A basic mass assignment is a nonnegative rational set function on the eight subsets of a three-element frame, with exact total one. Belief sums masses of subsets; plausibility sums masses that intersect a query; commonality sums masses of supersets. The planning oracle computes these by explicit subset relations. The runtime uses fixed arrays and an independently organized inversion recurrence. For all frozen contracts, exact reduced-rational outputs agree. This is stronger than a floating-point tolerance check but remains same-owner software evidence.

The phase makes conflict visible. Unnormalized conjunctive combination moves products onto set intersections, including the empty set. Normalized Dempster combination is admitted only when one minus conflict is nonzero. Two disjoint categorical masses produce total conflict one and therefore a successful refusal rather than a fabricated normalized result. The failure of normalization is a useful counterexample to any rule that silently assumes all evidence sources can be combined. It does not establish that real sources are independent, reliable, or appropriately represented by this calculus.

A declared refinement maps each source label to a disjoint nonempty target block whose union is the target frame. Vacuous extension and marginalization recover every frozen source mass exactly. The pignistic summary distributes each nonempty focal mass uniformly among its members and reserves decision authority. Belief and plausibility supply a finite formal interval, not a calibrated real-world confidence interval.

## Source-faithful interpretation and decision discipline

The evidence calculus is useful precisely because it separates at least three layers that ordinary prose often collapses. A declared mass assignment is an authored mathematical input. Its derived belief, plausibility, commonality, pignistic, or credal quantities are deterministic consequences inside the declared frame. A real-world decision would be a further act requiring valid measurement, model choice, provenance, authority, and affected-party safeguards. No layer silently licenses the next. This phase therefore records not only exact values but the transformations, input hashes, protected gates, and counterexamples needed to explain why a downstream claim was admitted, represented, left open, or held for exact approval.

The thirty frames are intentionally finite and synthetic. Their varied labels test label preservation and caller isolation without asserting that a label names a person, mental state, physical variable, legal status, cultural category, or credential. Exact fractions remove numerical tolerance ambiguity, but exact arithmetic cannot remove semantic ambiguity or confer authority. Likewise, agreement between the planning oracle and the runtime is a bounded same-owner consistency result; it is not independent reproduction. The source-faithful ledger keeps Saelin's content provenance, Elowen's Git ancestry, inherited aggregate counters, Elowen's complete local inventory, canonical state, and delivery state in distinct layers.
