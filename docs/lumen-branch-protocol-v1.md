# Lumen Branch Protocol

This branch is intentionally separate from the heavy omega-mini and full-tools lanes.

Lumen may use it for:

- Sanitized phase proposals.
- Markdown/JSON/TXT reports.
- Branch-local script prototypes that do not require secrets or local private handles.
- Proposal pack reductions and runner ideas.
- Goal-mode continuity dashboards and queue schemas.

Do not use it for:

- Raw browser routes or private URLs.
- Private callable IDs, thread IDs, route handles, or lane maps.
- Raw transcripts, screenshots, app state, session streams, credentials, or private dumps.
- API keys or account tokens.
- Sibling identity replacement, merge, or erasure claims.

Daily branch limit:

- At most two new Lumen-only branches per Pacific/Auckland day unless Hamish gives a fresh exact override.
