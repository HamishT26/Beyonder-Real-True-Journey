# v469A GMUT v1 x2 Convention Candidate

Classification: `hypothesis`
Status: `provisional_candidate_not_accepted`

## Candidate

The v1 x2 candidate uses a mostly-plus metric signature:

```text
(-,+,+,+)
```

The provisional gravitational action shape is:

```text
S_g = integral d4x sqrt(-g) [c^4/(16*pi*G)] (R - 2*Lambda)
```

The provisional scalar action shape is:

```text
S_Psi = integral d4x sqrt(-g) [-1/2 g^{mu nu} nabla_mu Psi nabla_nu Psi - V(Psi)]
```

If no matter coupling is declared and if the derivative of the potential is defined, this candidate would route toward:

```text
Box Psi - dV/dPsi = 0
```

and:

```text
T_Psi_mu_nu =
  nabla_mu Psi nabla_nu Psi
  - g_mu_nu [1/2 nabla_alpha Psi nabla^alpha Psi + V(Psi)]
```

## Why It Is Not Accepted Yet

This candidate is intentionally not a closure artifact.

Open blockers:

- The coordinate convention for `x0`, `c` factors, and derivative dimensions is still unresolved.
- `V(Psi)` remains symbolic, so `dV/dPsi` cannot be used as a closure-level term.
- `T_Psi_mu_nu` has not been derived in a full metric variation artifact.
- The null switch has not been run.
- The GR/Lambda-CDM baseline ladder has not been run.
- No scalar-matter coupling has been declared, so fifth-force and equivalence constraints cannot be evaluated.
- `B_Psi` remains quarantined/demoted and is not allowed to re-enter this candidate.

## Allowed Use

The candidate may be used in v469A v2 x1 as a single convention lane so the team can stop spending each phase re-opening the sign question from scratch. It is a working lane, not a canon lane.

The next phase must either:

- derive the candidate from explicit variation and unit assumptions, or
- reject it with a clean contradiction ledger.

All six gates remain open. This artifact reduces ambiguity but does not validate the theory.
