# v466A GMUT v3 x1 Row-Lint Spec

Status: `HARDENING_FIELD_SCHEMA_HOLD`

`PASS_SCHEMA_ONLY` means the row shape is internally typed. It does not mean execution, validation, recovery, safety, proof, closure, or canon promotion.

## Required Row Statuses

| Status | Meaning |
|---|---|
| `PASS_SCHEMA_ONLY` | Fields are present and typed; row shape may be curated only. |
| `HOLD_PENDING_EXACT_ROW` | Required field is missing, ambiguous, context-only, advisory-only, unresolved, or awaiting binding. |
| `FAIL_CONTRADICTION` | Rows conflict, a demoted item is promoted, or support exceeds source authority. |
| `BLOCKED_OVERCLAIM` | Row implies validation, final physics, solved consciousness, empirical spiritual proof, fifth-force safety, or canon promotion. |

## Blocking Rules

- Provenance fields are required but cannot be used as truth, identity, or authority.
- Measurement technique requires a bounded measurand and uncertainty model.
- Null results or future null fixtures cannot be described as absence, recovery, validation, safety, or gate closure.
- Metric/action convention rows cannot derive scalar EOM, `T_Psi_mu_nu`, conservation, or null recovery.
- `B_Psi` remains demoted until a separate definition artifact exists.
- External constraints require candidate parameter, observable, bound form, unit, regime, source role, and assumption basis.
- Proxy rows require false-positive routes and cannot prove consciousness, identity, meaning, or spirituality.
- Journey/Solas material requires `journey_context_not_canon` and local path/line references if used.

## Conflict Key

Rows collide for contradiction review when all of these match:

- `measurement_technique`
- `measurand_or_quantity`
- `external_constraint_parameterization`
- `provenance_entity_id`

All six GMUT gates remain open.
