# v470 THOS v3 x2 Publication Stop Matrix

Phase: `v470_THOS_v3_x2`

Publication policy: current-phase curated only.

Allowed staged pattern: `docs/trinity-live-traces/v470-thos-v3-x2-*`

## Stop Rules

| Rule | Stop If | Action |
| --- | --- | --- |
| Raw material stop | Raw logs, session JSONL, screenshots, cache dumps, credential-bearing material, or private traces enter artifacts or staging. | Abort publication and isolate as non-curated material. |
| Allowlist stop | Staged paths differ from `docs/trinity-live-traces/v470-thos-v3-x2-*`. | Unstage unrelated files; do not broad stage. |
| Connector mutation stop | Drive, GitHub connector, Gmail, Calendar, cloud, deployment, or desktop mutation is implied without separate scoped approval. | Record as future approval-required task. |
| Cleanup stop | Delete, purge, cache cleanup, worktree cleanup, Drive cleanup, or repo cleanup is requested without a fresh explicit target list. | Produce cleanup candidate manifest only. |
| Advisory overclaim stop | Sibling advisory is framed as proof, publication authority, independent validation, or live execution evidence. | Downgrade to advisory and record evidence boundary. |
| Source authority stop | Public claim lacks source authority or source role. | Mark `open_gap` or remove claim. |
| GMUT overclaim stop | THOS report is framed as GMUT validation, gate closure, final physics, consciousness proof, or fifth-force safety. | Block publication until language is corrected. |
| Spend stop | Paid external action is uncertain or approaches `$100`. | Stop and request a new packet. |

## Practical Publication Rule

This phase can publish only the curated x2 artifacts. It cannot publish raw lane logs, session traces, old runner logs, broad generated material, screenshots, or unrelated background worktree dirt.
