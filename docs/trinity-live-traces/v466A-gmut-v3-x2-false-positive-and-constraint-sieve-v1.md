# v466A GMUT v3 x2 False-Positive And Constraint Sieve

Status: `SOURCE_AUTHORITY_TO_ACCEPTANCE_THRESHOLD_HOLD`

This sieve exists to prevent helpful standards, source links, null results, external bounds, and proxy language from being mistaken for validation.

| Sieve | False-positive route | Required discriminant |
|---|---|---|
| Source authority not support | Official or primary source presence mistaken for support. | List claim IDs supported, not supported, or contextualized. |
| Standard not validation | Standard compliance mistaken for physics validation. | Separate schema conformance from derivation and empirical result rows. |
| Null not absence | Null result mistaken for absence or recovery. | State tested regime, detection limit, residual definition, and non-tested regimes. |
| Constraint not safety | External bound mistaken for model safety. | Map parameter to observable and bound with assumptions before compatibility language. |
| Proxy not consciousness | Behavioral or textual proxy mistaken for consciousness. | List proxy target, alternatives, discriminant tests, and public claim boundary. |
| Agent identifier not personhood | Lane or tool identifier mistaken for personhood or hidden memory. | Keep agent identifiers as process attribution only. |
| Journey context not canon | Narrative resonance mistaken for physics validation. | Require local path/line references and `journey_context_not_canon` classification. |

All six GMUT gates remain open.
