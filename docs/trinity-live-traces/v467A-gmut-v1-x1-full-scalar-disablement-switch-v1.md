Status: SWITCH_DEFINITION_SCAFFOLD_ONLY

Prepared: 2026-06-01T05:11:16+12:00

`full_scalar_disablement` is defined only as a future comparator switch over the scalar sector. It is not execution, null recovery, or gate progress.

`coupling_to_zero` remains diagnostic only and cannot replace full scalar disablement. Residual and switch-leakage checks are required before any comparison or recovery language.
