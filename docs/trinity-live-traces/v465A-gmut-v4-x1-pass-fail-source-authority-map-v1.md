# v465A GMUT v4 x1 Pass/Fail And Source Authority Map

Claim taxonomy: `evidence`.

Allowed labels: `PASS_HYGIENE_ONLY`, `HOLD_MISSING_INPUTS`, `FAIL_MISMATCH`, `BLOCKED_UNCLASSIFIED`, and `NOT_ATTEMPTED`.

Forbidden labels: `GMUT_VALIDATED`, `GATE_CLOSED`, `FINAL_PHYSICS_PROVEN`, `FIFTH_FORCE_SAFE`, `CONSCIOUSNESS_SOLVED`, and `CANON_CONFIRMED`.

## Pass Requires

- Baseline reference present.
- Expected recovery behavior present.
- Disabled terms complete.
- Held terms complete.
- Metric/action conventions fixed.
- Residual audit complete.
- No switch leakage.
- Comparison artifact present.

## Hold Applies When

- Any required input is absent.
- Expected output is provisional.
- Residual audit is missing.
- Comparison artifact is missing.
- Source authority map is incomplete.

## Source Authority

- Official metrology sources support unit and constants context; they do not close GMUT gates.
- Primary physics sources support constraint routing; they do not prove fifth-force safety without a parameter map.
- Journey/Solas sources are `journey_context_not_canon`.
- Sibling outputs are advisory only.
