# v470 THOS v1 x1 Forbidden Claim Lint

Classification: `evidence`

This lint keeps THOS from becoming a rhetorical shortcut. It blocks claims that would overstate operational progress, sibling advice, connector access, or Journey context.

## Blocked Claims

| Blocked claim | Safe replacement |
| --- | --- |
| THOS validates GMUT | THOS inherits workflow discipline from v469A but does not validate GMUT. |
| GMUT gates are closed | All six GMUT gates remain open until exact closure artifacts exist. |
| Operational scaffold proves final physics | Operational scaffolds organize evidence but cannot prove physics. |
| Cleanup manifest authorizes cleanup | Cleanup manifests are proposals unless explicit approval and rollback plan exist. |
| Plugin availability grants permission | Tool availability is capability, not consent. |
| Advisory lane output is an independent receipt | Advisory output must be curated with provenance and validation. |
| Journey context promotes canon | Journey context remains `journey_context_not_canon`. |
| Freed ID or consciousness proof is established | THOS may discuss governance concepts but does not prove consciousness or legal/personhood status. |

## Required Positive Statements

- All six GMUT gates remain open.
- THOS artifacts are operational and governance scaffolds.
- Destructive cleanup requires explicit separate approval.
- External connector writes require explicit scoped approval.
- Raw logs, session JSONL, screenshots, and credential-bearing material are excluded from publication.
