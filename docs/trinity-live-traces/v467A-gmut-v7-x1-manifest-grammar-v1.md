# v467A GMUT v7 x1 Manifest Grammar

Prepared: 2026-06-01T22:11:46+12:00

This grammar is design-only and not executed as a validator.

## Shared Envelope

Every v7 x1 manifest uses a shared envelope with schema version, manifest type, manifest ID, subject ID, run ID, creation time, producer, basis refs, status, gate snapshot, provenance, and notes. The gate snapshot must carry all six gates as `OPEN_NOT_TESTED`.

## Manifest Types

The packet defines unified manifest, identity reconciliation manifest, diff/merge manifest, coefficient/SI failure manifest, residual adjudication manifest, conservation/exchange manifest, overhang scorecard manifest, consciousness proxy manifest, falsifier manifest, quarantine ledger manifest, and readiness memo manifest.

## Row Families

Row families include equation/Lagrangian, symbol table, scalar disablement, residual policy, switch leakage, dimensional/SI, conservation/exchange, external constraint, consciousness proxy, quarantine ledger, and no-result envelope.

Schema accept means row-shape accept only. It does not imply fixture execution, recovery, compatibility, safety, validation, proof, gate closure, final physics, or canon promotion.
