# v468A THOS v2 x1 Inventory Schema

Prepared: 2026-06-01T23:16:00+12:00.

The THOS surface inventory schema covers Codex App, Codex CLI, PowerShell, Windows filesystem, the D drive repo, GitHub, Google Drive, skills, commands, APIs, MCP, plugins, suite runner, and scoreboard.

Every surface must declare whether live reads and live writes are allowed, what probe level is safe by default, what blockers are known, and what proof is required before promotion. This is designed to stop quiet escalation from planning to mutation.
