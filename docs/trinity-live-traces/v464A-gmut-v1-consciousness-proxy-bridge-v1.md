# v464A GMUT v1 Consciousness Proxy Bridge

Status: proxy-only; consciousness measurement bridge remains open.

This artifact keeps consciousness as an operational proxy research hypothesis. It does not prove consciousness, solve subjectivity, or add physical backreaction.

## Allowed Proxy Classes

- Reported state marker: human-reported state labels used as metadata in a controlled protocol.
- Behavioral task marker: task timing, accuracy, or response-pattern features.
- Physiological signal feature: predefined signal features only if ethically and legally collected.
- Agent runtime marker: operational transcript/tool-state marker, not personhood or hidden-memory proof.

## Not Allowed

- Consciousness confirmed.
- Subjectivity measured as physics.
- Spiritual proof.
- Backreaction source term.
- Personhood proof from operational continuity.

## Future Protocol Requirements

Future work needs a predefined proxy variable, control condition, falsification criterion, ethics/privacy boundary, analysis plan, and no causal claim unless separately demonstrated.
