# v470 THOS v2 x1 Retention And Source Authority Ladder

Classification: `evidence`

The source ladder prevents THOS from upgrading weak evidence into strong claims.

## Source Authority

| Class | Claim ceiling |
| --- | --- |
| `durable_repo` | Local artifact existence and curated content. |
| `local_generated` | Locally generated report or schema content. |
| `tool_output` | Observed tool result for that run. |
| `advisory_only` | Critique, wording, blocker, or design advice. |
| `external_context` | Cited context or standards reference. |
| `journey_context_not_canon` | Terminology history or hypothesis routing when locally cited. |
| `open_gap` | Unknown or not verified. |

## Retention Ethics

Preserve durable phase artifacts by default. Treat raw operational materials as private until screened. Do not delete without a manifest, approval, and rollback or repair route. Preserve provenance for sibling and advisory receipts. Prefer minimal public summaries over bulk exposure.
