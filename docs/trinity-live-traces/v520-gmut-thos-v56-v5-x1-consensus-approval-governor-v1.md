## Approval Test

Each approval bundle should be checked for five qualities before execution:

1. Safe: it avoids destructive, private, external, and irreversible actions.
2. Feasible: it can be executed with current tools and existing lanes.
3. Useful: it improves continuity, orchestration, evidence quality, or phase execution.
4. Evidence-bound: claims are backed by receipts, source ledgers, tests, or explicit blockers.
5. Reversible: changes are repo-scoped and auditable through git history.
