## Added Requirements

- Provenance rows need entity, activity, and agent separation.
- Field overlays need required-field schema discipline before any schema pass.
- Proxy or dataset rows need measurement technique, data structure, and quality context.
- Numeric rows need SI unit, quantity/measurand semantics, and uncertainty model.
- Metric/action rows need convention, variation target, boundary policy, and integration-by-parts policy.
- External bound rows must not become detection, compatibility, or safety claims.
- Consciousness proxy rows must not become personhood, identity, hidden-memory, solved-consciousness, or spiritual-proof claims.
