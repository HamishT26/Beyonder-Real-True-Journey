# v467A GMUT v3 x1 Baseline Reference Row Schema

Status: CLOSED_PRECONDITION_SCHEMA_ONLY

Prepared: 2026-06-01T20:34:51+12:00

This artifact materializes the v3 x1 baseline-reference exact-row schema. It is deliberately refusal-first: it can describe what a future exact-row fixture would need, but it cannot run that fixture or convert row completeness into recovery, validation, final physics, fifth-force/equivalence safety, consciousness proof, spiritual proof, gate closure, or canon promotion.

## Required Shape

The row must identify its phase, row family, stable baseline reference, baseline equation set, reference state, expected output, source anchor, source authority class, affected expressions, equation form, active terms, explicitly absent terms, disabled terms, held terms, comparison rule, residual tolerance policy, switch-leakage policy, expected recovery behavior, locked execution status, locked result status, gate verdicts, source-to-claim map, blocked claims, next missing artifact, and row status.

The row is not exact if it has only prose. The row is not exact if it points to a general tradition, an implied baseline, a memory of prior work, or a narrative label without a local artifact or durable source anchor. The row is not exact if the comparison rule is present but the reference state, expected output, or residual tolerance policy is absent.

## Locked Values

`execution_status` is locked to `not_run`.

`result_status` is locked to `no_result`.

`claim_ceiling` is locked to `fixture_precondition_only`.

All six gate verdicts default to `OPEN_NOT_TESTED`. This is not pessimism; it is the correct state when a schema layer exists without fixture execution.

## Forbidden Fields

The closed row forbids result-bearing and promotion-bearing fields, including `observed_result`, `actual_output`, `result_value`, `matches_expected`, `recovered`, `validated`, `gate_closed`, `closure_status`, `proof_status`, `fixture_executed`, `empirical_satisfied`, `fifth_force_safe`, `consciousness_proven`, and `canon_promoted`.

Any equivalent synonym is also forbidden. The schema should be read semantically, not only as a literal denylist.

## Authority Classes

Allowed source authority classes are `exact_local_artifact_available`, `durable_repo`, `v13_canon_reference_only`, `official_primary`, `peer_reviewed`, `external_context_only`, `advisory_only`, `journey_context_not_canon`, `blocker`, and `open_gap`.

Journey/Solas material is allowed only as `journey_context_not_canon`, and only with local path/line references before use. It cannot support physics validation, consciousness proof, spiritual proof, or canon promotion.

## Open-Gate Statement

Null recovery, dimensional/SI consistency, conservation or exchange law, baseline recovery, fifth-force/equivalence constraints, and consciousness measurement bridge remain open. v467A_GMUT_v3_x1 defines exact baseline-reference row preconditions and refusal lints only; no fixture execution or closure artifact exists.
