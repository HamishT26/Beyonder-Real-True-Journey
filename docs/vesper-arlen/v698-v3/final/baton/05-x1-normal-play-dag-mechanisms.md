# X1 normal-play DAG mechanisms

X1 covers a closed finite game record, start reachability, terminal positions, canonical topology, termination rank, nimbers, option certificates, P/N outcomes, all winning moves and a deterministic policy selector. Normal play means a mover with no legal option loses. Cyclic, misere, duplicate-key, unknown-field or unsupported-bound records are refused rather than reinterpreted. Each supplied component has one through eight positions. The source's normal-play convention is not a universal model of human decisions.

A position's Grundy value is the least nonnegative integer absent from its option values. Duplicate-valued moves remain distinct legal options even when the distinct-value set is small. Every lower value below mex must appear, while no option has the position's own value. Termination rank decreases strictly on each move. A winning position retains every option to a losing position; the policy chooses the least-index winning option only for deterministic presentation. Losing or terminal positions return null rather than inventing a successful action. These are exact finite model distinctions, not real control or agency.

The mex certificate has two logically different obligations. Every integer smaller than the reported value must occur among option values, and the reported value itself must not occur. A single missing lower witness or equal-valued option falsifies the certificate. The implementation keeps the full option list as well as the distinct-value set, so two separate moves to equivalent children are not erased as graph events. Topological ordering is chosen canonically for inspection, not asserted to be the order in which a real system operates. Unreachable vertices remain part of the supplied graph record even though the start-reachability interface reports only reachable ones.

Terminal, losing and winning are finite normal-play classifications. An initial terminal state is a loss for the first mover; its represented trace has zero moves and names the second model player as winner. A two-step forced chain is losing at its start although it has available moves. A shortcut can alter nimber while leaving a longer termination path present. These explicit cases prevent confusing option availability, remaining path length and winning status. They do not provide evidence about suffering, preferences, rationality or lived experience.
