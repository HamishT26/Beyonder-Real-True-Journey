# X2 sums and finite certificates

X2 covers disjunctive-sum values, the complete Cartesian move graph, product outcomes, all winning coordinate moves, all-state mex/XOR certificates, bounded Nim contexts, complete path-length counts, a represented model trace, evidence gaps and authority reservations. A sum move changes exactly one component. Product values are calculated from the complete product graph and compared with component XOR rather than simply asserted equal. The recursive specification and reverse-DAG production agree on the frozen cases.

Equal nimbers can cancel in a sum: two winning components can form a losing combined position. Ordinary addition would be wrong. The bounded Nim-context comparison checks every declared heap from zero through the supplied bound; it is not a proof about all arbitrary games. Path counts retain complete terminating plays beyond the declared observation horizon rather than silently dropping them. The deterministic trace is represented because as-if player labels establish no autonomous agent. All real-world evidence-role labels still leave externally_verified false; claimed authority labels grant no authority, rights, production or Stage20 permission.

For a concrete sum counterexample, each component may have one legal move to a terminal position. Each start then has value one and is winning by itself. In the disjunctive sum the value is one XOR one, which is zero. The first model player must move in one component and leaves the other component's final move to the second. Ordinary arithmetic would instead give two and incorrectly suggest a winning sum. The stored boundary cases calculate the complete product graph and keep each coordinate-labelled option, so this distinction is inspectable without importing a physical or psychological interpretation.

The all-state certificate is stronger than checking just the designated start. It compares every supplied Cartesian position with its option mex and component XOR. Nevertheless, these are bounded supplied graphs, not a machine-checked universal theorem, a new proof of Sprague-Grundy theory, or independent reproduction. Extending to misere play, cycles, chance, hidden information, partisan moves or multiple real people requires a different declared model. The current refusal is a truthful domain boundary rather than an incomplete implementation silently promoted as general intelligence.
