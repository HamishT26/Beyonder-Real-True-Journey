\section*{Finite first-order term rewriting}
A rewrite system is a finite set $R=\{\ell_i\to r_i\}$ over a finite signature. For a ground term $t$, one step $t\to_R t'$ replaces a matched subterm $t|_p=\ell_i\sigma$ with $r_i\sigma$. The bounded reachable set is $\operatorname{Reach}_{R,d,N}(t)$ under explicit depth $d$ and state cap $N$. A local peak $u\leftarrow_R t\to_R v$ is boundedly joinable only when the declared searches find a common descendant. The finite predicate
\[
C_{d,N}(R,t)=\bigwedge_{u\leftarrow t\to v}\left(\operatorname{Reach}_{R,d,N}(u)\cap\operatorname{Reach}_{R,d,N}(v)\neq\varnothing\right)
\]
is not a universal confluence theorem, a physical equation, or empirical GMUT evidence. No new tensor, coupling, likelihood, unit, or field observation is introduced.
