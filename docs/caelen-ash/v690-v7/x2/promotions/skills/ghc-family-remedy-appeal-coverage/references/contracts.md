# Contract routing reference

Merged operations: remedy_route, appeal_window, explanation_coverage.

The companion public runner is `ghc_family_remedy_appeal_coverage.txt`. Its standalone intake envelope is intentionally narrower than the owner-phase executors: it validates an allowed operation name, a finite record list and an explicit false authority flag, then returns a deterministic count and refusal envelope. It does not reproduce the Caelen phase, confer authority or establish real-world behavior.

All source phase-local skills remain attributable. Consolidation is packaging, not independent validation or new scientific evidence.
