# Screen empirical adapters

1. Count real input rows and distinguish official observations from synthetic fixtures.
2. Verify source, format, calibration, transformation, exclusion, and version lineage.
3. Require a frozen baseline, analysis rule, covariance or uncertainty model, and blind holdout where applicable.
4. Require participant and operational safeguards for real THOS arms.
5. Require independent review before any promoted scientific result.
6. With any missing requirement, emit a zero-row or missing-input receipt and run no fit.

Protocol readiness is not empirical confirmation.
