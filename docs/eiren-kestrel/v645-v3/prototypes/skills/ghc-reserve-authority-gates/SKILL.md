# Reserve authority gates

1. Identify every conclusion requiring competent legal, regulatory, cultural, Maori, privacy, or affected-party authority.
2. Separate neutral technical context from decisions about rights, legitimacy, wording, data governance, or remedy.
3. Emit refusal cases for missing authorities and preserve unknown as unknown.
4. Use no real protected, identity, beneficiary, property, or location data.
5. State the exact evidence and authority required to reopen each gate.

Do not draft an authority's conclusion or treat consultation as delegated authority. Maori concepts remain under Maori authority.
