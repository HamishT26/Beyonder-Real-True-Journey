# Build a sequential evidence board

1. Declare the null, filtration, nonnegative evidence process, threshold, and stopping rule before reading outcomes.
2. Distinguish a valid e-process fixture from naive repeated fixed-horizon testing.
3. Record every synthetic update, threshold crossing, continuation decision, and failure.
4. Require external empirical evidence and independent review outside the synthetic board.
5. Emit `NOT_READY_FOR_STAGE_20` whenever any external gate is open.

Synthetic anytime-valid arithmetic does not establish scientific confirmation, proof, canon, or Stage 20 readiness.
