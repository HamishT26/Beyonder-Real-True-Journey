# Audit static accessibility

1. Require a descriptive page title, one main landmark, ordered headings, visible status, and labeled tables.
2. For complex maps or charts, require a short purpose alternative, linked long description, and equivalent data table.
3. Include coordinate reference and epoch context when coordinates appear.
4. Reject meta refresh, timed redirects, disappearing evidence, and visual-only reading order.
5. Preserve explicit manual and affected-user evaluation reservations.

Automated structure checks are not complete accessibility conformance.
