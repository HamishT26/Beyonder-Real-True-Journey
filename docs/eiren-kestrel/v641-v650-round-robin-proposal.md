## Quality gates replacing raw count inflation

| Gate | Requirement |
|---|---|
| Cardinality | Required files/rows exist and parse |
| Semantic uniqueness | Normalized duplicate ratio reported; pilot target at least 0.70 unique units for research findings, with human audit |
| Claim-evidence coverage | Every outward scientific/legal/current-state claim links to a source, test, or explicit E0/E1 label |
| Source independence | Common upstream sources grouped; 100 citations to one root are not 100 independent supports |
| Negative evidence | Contradictions, null results, and excluded regions retained |
| Reproducibility | Command, environment, seed, inputs, and expected outputs recorded |
| Privacy/security | No private IDs, routes, transcripts, absolute paths, credentials, hidden reasoning, or raw app state |
| Completion | Checklist passes or an exact open-gap receipt exists; watcher start is not completion |
| Git truth | Owned branch clean, exact staged files, push succeeded, local equals upstream |

The familiar 25/15/10/5/15/100/100 shape may remain as a compatibility fixture, but it must not be used as the scientific quality score.
