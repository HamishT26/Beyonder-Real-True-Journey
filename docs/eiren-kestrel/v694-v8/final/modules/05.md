# 05 — CTL semantics and finite-model conventions

A Kripke structure is a finite set of states, a total transition relation and a state-labeling function. Totality is required so the path quantifiers have infinite continuations under the declared convention. EX and AX use existential and universal predecessor sets. EF, AF, EU and AU are least fixed points; EG and AG are greatest fixed points over the finite powerset lattice. The implementation reports complete state sets and iteration traces. A separate path-and-cycle oracle checks thirty x2 temporal results. Same-owner algorithm diversity is useful bounded evidence but not independent reproduction.
