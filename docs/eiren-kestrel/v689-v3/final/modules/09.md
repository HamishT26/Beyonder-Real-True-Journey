# Module 09: Packages and reproducibility

## Packages and reproducibility



Three direct additions were frozen and installed only after planning: Pint 0.25.3, uncertainties 3.2.3, and pyDOE3 1.6.2. Their nine-wheel closure includes exact versions of flexcache, flexparser, NumPy, platformdirs, SciPy, and typing_extensions. All reviewed wheels contained bundled license paths and no unsafe archive paths. The actual offline installation used a full nine-wheel `--require-hashes` file. The point-in-time advisory query reported zero known vulnerabilities for the nine exact versions. This is neither exhaustive security nor future assurance.

The installed snapshot compares 2718 unchanged wheel members and binds 5174 materialized site-package files through aggregate digest `085e629f218b6508c096253708e1ec1812dd34d2a02576aa9b35cabdbfe5b583`. Pint converted a synthetic two-kilometre quantity and rejected a length-to-time conversion. uncertainties reproduced a synthetic independent quadrature example and rejected a negative standard deviation. pyDOE3 built small full-factorial matrices and rejected a malformed factor count. These are bounded API behaviors, not measurements, experimental results, endorsements, or professional validation.

The package closure includes libraries with capabilities this phase did not use. Availability is not authorization to invoke unsafe serialization, cache untrusted objects, make network calls, or treat every dependency as relevant. Pip advertised a newer version but the host and package toolchain were not upgraded. The Codex desktop remained user-managed.
