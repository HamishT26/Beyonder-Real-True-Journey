# 11 — Closeout and canonical discipline

The final commit may contain only additive closeout metadata, reports, validation records, manifests and this prepared baton. It must be the direct child of x2. After a successful push and fresh four-way equality, one owner-scoped metadata canonical may run. It must not execute domain suites, source suites, browser models or installers.

If the canonical succeeds, invocation/success/replay becomes 1/1/0 and it is never replayed. If it fails, it earns zero canonical success credit and only a named failed dependency may receive a separately labelled recovery. The full repository suite remains outside this owner phase.
