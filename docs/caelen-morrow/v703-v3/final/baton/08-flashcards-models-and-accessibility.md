# 08 — Flashcards, models and accessible structure

The content-addressed context deck contains 612 cards across 21 modules and four tiers. It includes one owner card, three pillar cards, eight practice cards, 300 new task cards and 300 inherited zero-credit task cards. Five finite model records provide transparent structural examples.

HTML and Markdown use headings, lists, labelled tables and textual summaries. This is structural static evidence only. Manual browser, assistive-technology, cognitive-accessibility, Maori-language and affected-user evaluation remain reserved.
