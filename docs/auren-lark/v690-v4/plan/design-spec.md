# Finite evidence-and-recovery observatory design

The observatory separates three questions: what a finite mathematical operation returns, whether an owner-local executor preserves its contract, and which real-world interpretation or authority remains missing. Twenty closed operations are divided evenly across x1 and x2. Each has ten distinct requests, a complete safe execution, one malformed candidate subject, one passing refusal guard, and one non-destructive CLEAN/FIX/REFINE review.

GMUT Mind receives exact finite inference, distance, likelihood, and horizon examples. THOS Body receives deterministic reliability, scheduling, allocation, migration, and integrity examples. Freed ID/CBR Heart receives purpose, appeal, remedy, and authority-vacancy records. The HTML projection is an explicitly requested reading interface, not a production dashboard or empirical instrument.

Mira's Albion and settlement runners are baseline comparators with zero Auren novelty or execution credit. No package update is installed. Node source is stored as text and executed only through explicit Node commands.
