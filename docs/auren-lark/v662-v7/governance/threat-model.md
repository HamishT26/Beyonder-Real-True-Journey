# Auren Lark v662-v7 exact-delta threat model

## Assets

Exact Git ancestry, owner attribution, immutable x1, sparse scope, changed-file
manifests, bounded declaration contracts, retained failures, privacy boundaries,
and successor-route truth.

## Threats and controls

- Binary layouts require an explicit standard byte order and refuse native or absent declarations.
- Permission normalization rejects non-integer, negative, and out-of-mask values without touching a filesystem.
- Nested budgets and size products reject negative, excessive, and overflow-prone synthetic declarations before allocation.
- URI members carrying authority, query, fragment, encoded separators, or traversal segments fail closed without dereference.
- Media-type parameters use a bounded grammar and quarantine duplicates, unsupported charsets, and excess parameters.
- Digest and DSSE checks validate declared shape only; signature, provenance, cryptographic agility, and trust stay unclaimed.
- Attestation subject-name collisions, leap-second timestamps, and non-canonical JSON Pointer array indices remain reserved or rejected.
- Report revisions, terminology revisions, and custody transitions require exact paired identifiers and conflict quarantine.
- Scope remains the exact owner delta and literal test dependencies.
- One canonical success is permitted and never replayed; exact-title reread and acknowledgement are required for delivery.

## Residual risk

This is not exhaustive security, platform completeness, production assurance,
complete privacy or accessibility, independent reproduction, legal review,
cultural ratification, or Maori authority. Residual risks remain exact-gated.
