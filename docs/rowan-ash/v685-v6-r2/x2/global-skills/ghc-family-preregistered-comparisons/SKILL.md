# Preregistered Comparisons

This package combines 4 validated local guides. Read the relevant source guide under references before choosing an operation. The original guides remain unchanged in the Rowan remaster evidence bank.

## Workflow

Start with scripts/ghc_family_claim_evidence_lab.py --help using Python with UTF-8 enabled. All five shared core runners are included so imports are portable. Select a current owned output path explicitly. The contract lab accepts --families and --output; the schedule accepts --output; the fraction search accepts --start, --end, and --output; the plan contract accepts a plan and optional --output. The seal accepts exact source and final commits plus an explicit scope policy.

Use the source-specific accepted and adverse examples to understand the scope. Preserve failures, definitions, and current authorization. A planning projection never creates a task or sends a message. A finite arithmetic witness never proves a universal conjecture. A metadata contract never verifies personhood, scientific endorsement, cultural authority, or a real credential.

## Canonical receipt boundary

The scoped seal offers a preflight mode and an explicitly requested canonical mode. A canonical invocation writes an exclusive invocation marker. An existing receipt or marker blocks replay. Read the current owner policy, verify the exact final revision and remote equality, and keep its receipt outside the sealed repository delta. Never use a historical phase's canonical command as a smoke test.

## Compatibility and rollback

Source guides and runner hashes are listed in references/promotion.json. Global installation is a byte-preserving copy of this package. No earlier global skill is deleted. A rollback changes the caller's package selection to its previous validated source; it does not erase the new package or any retained negative. Global availability does not prove that an already running task has reloaded its skill catalogue.
