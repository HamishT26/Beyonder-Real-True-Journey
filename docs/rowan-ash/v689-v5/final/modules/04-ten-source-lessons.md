# Module 04 - What the ten-source window changed in this phase

The source review is deliberately bounded. Rowan read selected overview excerpts and complete small truth or correction records from the ten most recent completed bundles, then bound those exact checkout bytes to their named Git blobs. Only the immediate Elaren baton was read completely through EOF. The source-window file gives the paths, hashes and character spans so a successor can see the difference between an excerpt review and a full-document read. No historical test execution or universal archive-coverage claim is attached to this review.

Elowen Cairn v688-v5 demonstrates why a final check should test the intended claim rather than the capitalization of prose. Its first canonical failed on a literal wording expectation even though the overview communicated the same-owner limitation. The later correction retained the original failed aggregate and isolated the failed dependency. Rowan uses structured booleans and typed receipts for material state, while retaining human-readable explanations. A document still needs review, but a sentence's case should not become a hidden proxy for scientific or lifecycle truth.

Veylora Quen v688-v6 makes representation boundaries concrete through firmware-record preservation. It separates address arithmetic, sparse missingness and digest binding from executable firmware safety or ownership. Its retained alias and final-scope corrections show why a label must match the implemented behavior. Rowan therefore gives each geometry operation an explicit payload and output, describes the rational coefficient field, and states where a helper's scope ends. A small graph result cannot be renamed into a physical or governmental conclusion.

Sylven Arc v688-v7 preserved partial materialization and later corrections rather than overwriting a failed builder's output. Its history also records that a per-path Git reader could be a poor fit for a large source bank. That lesson was directly relevant here: an initial recursive source read and a later broad object batch were too slow, and their failures were retained. Rowan used direct selected paths, batched object bindings for the history window, and a different transport recovery based on already materialized bytes. The purpose of the change was to reduce the necessary work, not to manufacture a passing replay of a source validator.

Tessarin Reed v688-v8 requires complete finite domains for its deterministic automata conclusions. A missing transition, an undeclared symbol or an omitted enumeration bound changes what a result means. Rowan applies the same discipline to finite graphs and complexes. Vertices and facets are explicit; duplicate vertices and unsupported edges are refused; matrix sizes are bounded. Rational Betti numbers are labelled as rational results. A bounded enumeration or rank calculation does not prove that an external system has the same state space or topology.

Caelen Morrow v689-v1 keeps nondeterministic reachability separate from real-world agency, identity and operational liveness. A reachable state in a supplied table is not evidence that a real event occurred. Rowan carries that distinction into harmonic modes, graph components and zero-energy states. The words connected, harmonic and stable have mathematical definitions here. They do not evaluate wellbeing, moral worth, consciousness, responsiveness or social legitimacy. Keeping the definitions close to the results makes the tools easier to reuse without changing their claims.

Seren Talewood's original v689-v2 closeout was held for Hamish. A completed owner bundle did not authorize the next activation by itself. That historical hold remains a useful example even though a later remaster changed the future workflow. Rowan's repository likewise keeps PREPARED_NOT_SENT separate from any external delivery acknowledgement. A canonical pass, a route projection and a sent native message are distinct records. Neris should preserve that separation in its own phase even when the next name seems obvious.

Seren v689-v2-r2 introduced a reusable owner-root approach and showed why provenance is not the same as Git ancestry. A blank root can truthfully cite an earlier source without pretending to descend from it. Conversely, Rowan's present direct-child source relationship is not an orphan-root relationship merely because the checkout is isolated. The object transport recovery also adds a shallow-history boundary that must be named. These distinctions help future owners choose an efficient lane without rewriting what the repository actually contains.

Seren v689-v2-r3 supplies the current weighted roster and both-session candidate rule. It also retained DiskCache uninstalled after a public advisory and chose a different package for its declared use. Rowan followed the pattern of selecting packages for concrete operations, checking exact current artifacts, recording a point-in-time advisory query and exercising accepting and adverse inputs. A zero-advisory response is not a permanent safety certificate. The important result is a traceable selection and a bounded observed capability, with uncertainty still visible.

Eiren Kestrel v689-v3 shows the benefit of separate planning, x1 and x2 definitions. Its later test-scope correction did not turn an earlier failed aggregate into a pass. Rowan's initial plan similarly retained duplicate-request and newline failures before the first commit. Later x1 metadata-writer errors were corrected by reading and reusing already-passed receipts rather than rerunning calculations. The distinction between a result and the program that formats its summary prevents an output-parser bug from falsely invalidating or falsely recreating the underlying evidence.

Elaren Kestrel v689-v4 is the immediate source and the most direct canonical lesson. Its undefined SOURCE constant stopped the aggregate before components ran. A separate component recovery was valid, while the original aggregate remained failed. Rowan's final validation is designed around explicit anchors, static undefined-name checks, an exclusive invocation latch and a declared owner file set. The successor should inspect the actual final receipt for the result. A carefully written plan to avoid a failure is not proof that the failure was avoided until the relevant operation has run.

Taken together, these sources encouraged fewer implicit assumptions and clearer evidence layers. They did not supply new Rowan execution credit. The 200 inherited proposals are Elaren's explicit records, retained with their original identities and hashes, then reorganized through lossless keyed projections. That is a source-record refinement. It is not a new weaving experiment, an independent replication, a new scientific discovery or a cleanup of someone else's computer. The whole historical family corpus remains larger than the bounded source slice used here.
