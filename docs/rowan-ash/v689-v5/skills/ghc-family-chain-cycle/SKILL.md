# Chain Cycle

Accumulate signed endpoint contributions in the declared edge order. An equal-weight loop cancels; removing its closing coefficient leaves two endpoints. A chain being closed does not imply it is a boundary. Formal cancellation is not evidence of a real conservation process.

Use [the paired runner](../../../../../scripts/ghc_family_simplicial_chain_membership.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `chain_cycle` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N081` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: Equal cyclic edge coefficients cancel at every vertex; an opened path leaves only two endpoints. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.
