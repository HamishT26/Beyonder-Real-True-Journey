# Simplex Faces

Generate every nonempty face in dimension then lexicographic order. The empty face belongs to an augmented convention that this profile does not implement. Face counts alone do not identify a topological space. Compare a four-vertex simplex against the independently known counts 4, 6, 4, 1.

Use [the paired runner](../../../../../scripts/ghc_family_simplicial_faces_orientation.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `simplex_faces` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N001` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: Independent bitmask enumeration of every nonempty subset. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.

For an extension, state the coefficient field, orientation convention, resource limits and any additional evidence needed. Preserve a failed subject separately from a successful rejection predicate.
