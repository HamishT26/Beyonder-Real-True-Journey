# Weighted Laplacian

Use strictly positive integer weights and the same incidence convention on both sides of the diagonal weight matrix. Row sums must vanish and the operator must be symmetric. Negative weights belong to a different profile and defeat the simple positivity argument; do not admit them silently.

Use [the paired runner](../../../../../scripts/ghc_family_cochain_adjoint_laplacian.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `weighted_laplacian` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N131` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: Weighted path endpoint fluxes and adjacent interior weight differences. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.

For an extension, state the coefficient field, orientation convention, resource limits and any additional evidence needed. Preserve a failed subject separately from a successful rejection predicate.
