# Chain Boundary

Test whether the supplied oriented edge-chain vector lies in the image of the face-boundary matrix using exact augmented rank. The zero chain is always in the image, including when the image has rank zero. Do not silently supply a missing triangle face to make a loop bound.

Use [the paired runner](../../../../../scripts/ghc_family_simplicial_chain_membership.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `chain_boundary` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N091` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: The triangular loop bounds exactly when the supplied complex includes its two-simplex. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.
