# Graph Cycle Rank

Apply E minus V plus the number of connected components only to the admitted finite undirected graph. Do not substitute the formula for a directed-cycle analysis. A union-find redundant-edge count gives a structurally different small-case oracle. The rank describes the supplied graph alone.

Use [the paired runner](../../../../../scripts/ghc_family_graph_components_cycles.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `graph_cycle_rank` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N051` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: Connected n-cycle has n edges and n vertices, so E-V+1=1. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.
