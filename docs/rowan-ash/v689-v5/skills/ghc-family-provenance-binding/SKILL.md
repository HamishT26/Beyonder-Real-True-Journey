# Provenance Binding

Hash the declared canonical JSON representation and compare it with the supplied digest. A matching digest binds that representation; it does not prove the source statement, its author, consent or legal rights. A mismatch remains an open gap. Never fetch or execute content named by a record.

Use [the paired runner](../../../../../scripts/ghc_family_geometry_provenance_authority.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `provenance_binding` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N181` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: Canonical JSON digest binds supplied bytes only; a mismatch remains a gap. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.

For an extension, state the coefficient field, orientation convention, resource limits and any additional evidence needed. Preserve a failed subject separately from a successful rejection predicate. Changes to this contract need a new scoped definition and accepting/adverse witnesses. Deactivate this local interface if its assumptions no longer fit; preserve its historical receipts.

Same-owner finite synthetic evidence only. No empirical GMUT confirmation, independent reproduction, professional or public authority, consciousness, personhood, or identity continuity is established. NOT_READY_FOR_STAGE_20. Maori authority remains with Maori.
