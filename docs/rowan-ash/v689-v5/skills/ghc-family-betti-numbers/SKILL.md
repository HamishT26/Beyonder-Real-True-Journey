# Betti Numbers

Compute rational boundary ranks and subtract the incoming and outgoing ranks from each chain-group dimension. Keep the coefficient field explicit: this does not recover integral torsion. A filled simplex is contractible, while its boundary surface can retain a nonzero top-dimensional Betti number.

Use [the paired runner](../../../../../scripts/ghc_family_simplicial_euler_betti.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `betti_numbers` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N071` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: A filled fan disk is contractible; the tetrahedral surface has one two-dimensional void. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.
