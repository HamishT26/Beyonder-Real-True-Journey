# Boundary Squared

Compose the same unaugmented boundary map twice and retain exact cancellation. Missing faces or inconsistent orientations invalidate the premise. Test multiple tetrahedron permutations, including negative chain coefficients. Zero residual is an algebraic consistency check and does not establish empirical conservation.

Use [the paired runner](../../../../../scripts/ghc_family_simplicial_boundary_composition.py) with a UTF-8 JSON input file or standard input. Its input envelope has `op`, `payload` and `synthetic: true`; choose `boundary_squared` for this skill. Unexpected fields, wrong scalar types and unsupported scope are explicit refusals. The CLI writes a fresh output file only when a caller supplies `--output`.

The frozen example `RA6895-N031` is available in [the phase definitions](../../plan/new-proposals.json). Its independent oracle is: Every codimension-two face cancels with its opposite signed occurrence. Read the actual payload and complete typed result rather than relying on its title. The reusable evaluator does not import the frozen expected-value table.

For an extension, state the coefficient field, orientation convention, resource limits and any additional evidence needed. Preserve a failed subject separately from a successful rejection predicate. Changes to this contract need a new scoped definition and accepting/adverse witnesses. Deactivate this local interface if its assumptions no longer fit; preserve its historical receipts.
