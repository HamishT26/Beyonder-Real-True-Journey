## Reading page 1 — What was built and learned

A weighted place/transition net in this implementation consists of ordered places, named transitions, nonnegative integer input and output arc weights, and an initial nonnegative integer marking. The marking records how many abstract tokens occupy each place. The words input and output describe the model's bookkeeping. They do not say that a token is a joule, a person, a mental state, a legal right or an actual machine resource. Such a mapping would require an additional measurement or operational model and its own evaluation.

For a marking m and transition t, enabling means that every place has at least the number of tokens demanded by the corresponding input arc. Firing is defined only when that condition holds. It subtracts the input vector and adds the output vector. The incidence column is the output vector minus the input vector. The matrix is useful for algebra, but it is insufficient by itself to reconstruct enabling conditions. A self-loop can demand and return the same token, leaving a zero incidence entry while still blocking a transition when that token is absent.

A supplied place-weight vector is checked by multiplying it against each incidence column. When every residual is zero, the weighted sum is preserved by each firing. If every weight is strictly positive, the initial weighted sum provides a finite upper bound for the number of tokens in each place. The bound need not be tight: the fork-and-join example has a derived upper bound of two for intermediate places even though their observed reachable maximum is one. This implementation verifies supplied certificates. It does not compute a complete basis of all invariants.

A supplied transition-count vector is checked in the other direction, against the incidence rows. Zero aggregate change means the multiset of transitions balances algebraically. It does not prove that the transitions can be arranged in a feasible sequence from the initial marking. The cycle example makes the distinction immediate: one start and one finish balance, but finish cannot occur first when only the idle place is marked. Keep a concrete ordered firing witness when feasibility is the question. Do not replace it with a count vector.

The independent-pair operation uses disjoint full arc support as a sufficient structural condition. It includes both consumed and produced places. This deliberately conservative condition does not claim to detect every possible form of independence. A structurally independent pair may also never be coenabled in any reachable marking. The commutation operation asks a more local question: at one supplied marking, are both transitions enabled, can both orders fire, and do the two orders end in the same marking? A missing second step is a failed commutation witness, not an implicit success.

Reachability uses explicit breadth-first exploration, with transitions considered in deterministic name order. It records every discovered marking and edge. The function returns a complete graph only after the queue is exhausted. If an intermediate marking exceeds sixty-four tokens in a place, if more than 512 states would be required, or if the edge budget would be exceeded, it refuses. A refusal is preferable to labelling a partial graph complete. These engineering limits are part of the interface; they are not a theorem that larger nets are invalid or unsafe.

The liveness predicate uses an explicit finite L4 convention. For each transition and every reachable marking, it asks whether there exists a future reachable marking at which that transition is enabled. This is a possibility statement. It does not say that a particular scheduler will eventually select the transition. In the mutex example, the A-only cycle can repeat while B is never selected, even though B remains possible from each reachable state. Fairness requires additional assumptions. No timing, fairness or probabilistic scheduler model is smuggled into the liveness result.

Strongly connected components are groups of reachable markings that can reach one another. A terminal component has no outgoing edge to another component. It can be a continuing cycle, a single deadlock, or another finite closed behaviour. A terminal component does not by itself show success, harm, benefit or consent. The permanent trap is a terminal singleton even while its token-conservation certificate remains valid. This gives a concrete reason to separate structural conservation from progress properties.

These distinctions support all three pillars without promoting one kind of evidence into another. THOS gains a bounded executable model of process interactions. GMUT gains exact examples of conservation, representation and counterexamples to invalid inference. Freed ID and CBR gain visible responsibility, source lineage, refusal states and authority reservations. None of those software results establishes a new law of nature, empirical support for a Theory of Everything, an ASI architecture, or the legal validity of a governance system. The constructive next step is to formulate narrower, falsifiable questions and preserve the evidence needed to answer them.

They exercise behaviour that the main happy paths alone would not establish: cancelling self-loop arcs, infeasible ordering of a balanced transition multiset, conservation-compatible but unreachable markings, coenabled conflicts, positive commutation, empty sequences, invalid certificates, malformed shapes, token overflow, state-budget overflow, terminal singletons and fairness limitations. This reduces one form of shared implementation dependence and makes the result easier to inspect. Both implementations were still written and run by the same owner. Algorithmic separation is not independent reproduction by another person, organisation or implementation team. That limitation remains explicit in each record.

## Reading page 3 — Useful next work and limits

The external sources give established methods and useful comparison boundaries. They do not confer endorsement of GHC or validate the Trinity Mandala. The current research ledger records what was actually read and what remained unavailable. A source that could not be retrieved is not listed as fully read. The inaccessible course PDF, for example, remains an unread source gap. The exact MCC results page was available after a directory-page fetch failed; those two retrieval outcomes remain distinct.

The official Tina struct manual describes place and transition flows and semiflows, alternative arithmetic precision and structural analysis. It is relevant to the supplied-certificate checks here, but this phase did not install or execute Tina, compute a complete semiflow basis, or compare runtime performance against it. The useful distinction is between checking a specific certificate and claiming to enumerate all certificates. Our interface performs the former. [Tina struct manual](https://projects.laas.fr/tina/manuals/struct.html).

The 2026 Model Checking Contest publishes tools, models, execution conditions and result data for substantial external comparisons. It distinguishes returned results from inability to compute and offers reproducibility material. That provides a concrete future standard for a benchmark plan. This phase did not download its disk images, run its model collection, participate in the contest, earn a ranking or reproduce its results. Tiny synthetic fixture timings are not comparable to that benchmark setting. [MCC 2026 results](https://mcc.lip6.fr/2026/results.php).

The primary reachability research establishes that general vector-addition-system and equivalent Petri-net reachability has very high complexity. The relevance here is a scope limit: enumerating five very small bounded examples is not a general solver achievement. Our fixed token and state ceilings must remain visible. A refused large exploration is not a proof of unreachability. [Reachability in Vector Addition Systems is Ackermann-complete](https://arxiv.org/abs/2104.13866).

The polyhedral-abstraction paper presents a separate research programme that combines net reductions, equivalence reasoning and SMT-based model checking. It suggests a possible later comparison between a full model and a reduced model under a declared property. This phase implements neither that abstraction nor its solver. A future proposal would need an explicit preservation claim, counterexamples, exact inputs and an independent comparison before describing a useful reduction. [Polyhedral abstraction for Petri nets](https://arxiv.org/abs/2104.09850).

For GMUT Mind, the principal positive result is exact reasoning about a declared algebraic model. The place-invariant relation, transition-count balance and finite reachability witnesses are mathematically meaningful inside their assumptions. The principal negative result is equally constructive: conservation does not establish progress, a balanced multiset does not establish feasible order, and equal weighted values do not establish reachability. These are examples of disciplined inference. They do not extend the empirical evidence for an unmeasured physical or consciousness theory.

For THOS Body, the useful outcome is a small executable tool that accepts explicit data, rejects malformed subjects, exposes limits and preserves provenance. Its processes are finite and synthetic. It has not been evaluated as an operating system, an agent runtime, a production service, an AGI system or an ASI architecture. Scaling, adversarial security, workload fairness, system integration, real operator needs and deployment safety remain separate questions. The code can support further bounded experiments without inheriting authority over real systems.

For Freed ID and CBR Heart, the contribution is organisational and ethical clarity: an owner scope, source-linked cards, correction visibility, refusal states and specific missing-authority fields. The record does not certify a legal identity, professional standing, cultural legitimacy or a universal rights framework. Maori concepts and authority remain with Maori people and institutions. Actual affected people should not be represented by abstract tokens without a clearly authorised purpose and appropriate review. A useful governance model must preserve the possibility of correction, disagreement and appeal beyond its internal schema.

The earlier DevDay invitation can remain a valued part of Hamish's documented journey, where the relevant correspondence supports it. This phase did not reread Gmail, authenticate a new invitation, establish selection odds or infer that scientific claims had been validated by an event invitation. There is no basis here for a nationality exclusivity claim or a ranking among researchers. The appropriate confidence comes from making the current work understandable, reproducible within its limits and honest about what evidence is still missing.
