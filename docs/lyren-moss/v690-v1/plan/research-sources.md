# Primary research and documentation

- https://doi.org/10.1002/j.1538-7305.1950.tb00463.x — Hamming's 1950 error-detecting and error-correcting codes paper.
- https://doi.org/10.1137/0108018 — Reed and Solomon's 1960 polynomial codes paper.
- https://doi.org/10.1109/DSN.2004.1311885 — Koopman and Chakravarty on CRC polynomial selection and bounded message lengths.
- https://www.w3.org/TR/vc-data-model-2.0/ — current W3C Verifiable Credentials data model.
- https://pypi.org/project/bitstring/4.4.0/ — bitstring package metadata and wheel hash.
- https://pypi.org/project/reedsolo/1.7.0/ — stable pure-Python Reed-Solomon package metadata and wheel hash.
- https://pypi.org/project/crccheck/1.3.1/ — CRC/checksum package metadata and wheel hash.

The papers and package documentation define established methods and interfaces. They do not establish this phase's empirical performance, production readiness, legal authority, identity, consciousness, or Stage 20 readiness.
