# Cross-contact reservation

1. Require synthetic ingredients, equipment, routes, and records only.
2. Run `python -X utf8 scripts/ghc_family_cross_contact_reservation.py --output <owner-receipt.json>`.
3. Require one bounded valid fixture and five rejected mutations.
4. Keep every affected-party, food-safety, labelling, legal, and release decision outside the software receipt.

This is structural reservation evidence, not a real allergen assessment, food-safety determination, compliance statement, or Stage 20 result.
