# Formal Concept Analysis planning notes

The finite context is a triple of declared objects, attributes, and an incidence relation. Derivation maps object sets to their common attributes and attribute sets to their supporting objects. Double derivation creates closure operators. A formal concept is an extent-intent pair fixed by both derivations, and concepts are ordered here by extent inclusion.

This phase uses exhaustive subset enumeration only for the small declared contexts. It does not claim a scalable NextClosure implementation, a minimal Duquenne-Guigues basis, causal inference, empirical truth, identity inference, eligibility, legal or cultural authority, or production access control.

Primary metadata references are Ganter and Wille's Formal Concept Analysis book, RFC 8259, and WCAG 2.2. Source terminology does not supply Lyren execution results.
