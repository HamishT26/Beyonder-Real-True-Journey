11. Update shared family-current discoverability and route state additively, never by history deletion.
12. Produce modular evidence, gates, wellbeing, overview, closeout, seal, and route cards.
13. Stage and review the exact owner allowlist; preserve x1 immutability and zero deletions.
14. Commit and push the evidence boundary before final closeout when the lifecycle requires it.
15. Commit, push, and prove the exact final clean, zero-divergent, and fresh four-way equal.
16. Invoke one owner-scoped canonical completion; retain failures and never replay a success.
17. Reread the newest live route, uniquely resolve and reread the successor, and send one compact pointer.

Stop with an open route gap when the target is absent or ambiguous, the user has
paused or redirected, usage is exhausted, or a protected safety or authority gate
blocks progress.
