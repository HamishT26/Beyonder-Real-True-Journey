# Angle Unit Domain Board

Record unit symbol, quantity kind, valid domain, sign convention, and conversion status. Do not infer units from field names. Reject out-of-domain values, silent degree-radian or sexagesimal conversion, and any claim that schema validation establishes measurement accuracy.
