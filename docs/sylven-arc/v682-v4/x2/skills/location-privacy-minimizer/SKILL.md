# Location Privacy Minimizer

Default to no coordinates, vessel identity, route, timestamp, or place name. Use coarse synthetic categories only when structurally necessary. Require purpose, minimization, retention, access, remedy, and affected-party authority before any real location handling; reject inference and publication.
