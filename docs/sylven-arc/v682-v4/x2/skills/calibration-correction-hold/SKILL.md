# Calibration Correction Hold

Require instrument identity, traceable method, environmental context, repeated observations, uncertainty, competent review, and authorization before a correction can be accepted. In this phase all prerequisites remain absent. Reject correction values, certificates, calibration status, and fitness-for-navigation claims.
