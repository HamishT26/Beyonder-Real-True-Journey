# Scale Reading Nonobservation

Allow typed degree, arcminute, and optional arcsecond fields only when their values are explicitly vacant or synthetic test values. Require a nonobservation marker and provenance digest. Reject claims of a real reading, accuracy, uncertainty, calibration, position, or navigational result.
