## What the examples establish

The crossed-bits model has four worlds. Observer a sees one partition and observer b sees another. Neither the symbols nor the partitions represent actual people. Each class lists alternatives that the model treats as indistinguishable. For a proposition p, K_a p holds only when every world in a's class satisfies p. Possible p requires at least one such world. These definitions are declared inputs and finite calculations.

Everyone information requires both individual conditions. Distributed information uses the intersection of observer classes. Common information follows any finite chain of observer links. In the common-barrier example, everyone p holds at world zero while common p holds nowhere, because an alternating link path reaches a world where p is false. The implementation retains this counterexample instead of equating the two notions.

A public Boolean announcement removes worlds where its proposition is false and restricts the relations and valuations together. In crossed bits, announcing p retains worlds one and three. The browser check observed that reduction and then observed reset restore all four worlds. The model selector also displayed the common-barrier counterexample. These checks used the page's accessibility state; no image or screenshot was created.

The Moore-style formula p and not K_a p supplies a second useful counterexample. It can be true before announcement and false after its own announcement, because the remaining alternatives all satisfy p. A truthful announcement is therefore not a promise that every epistemic clause in its content remains true afterward. The implementation makes empty announcement support explicit. It does not label an empty restriction a valid nonempty input model.
