# 05 — Perfect-information safety mechanisms

X1 covers profile grammar, action posts, controllable and universal predecessors, greatest safe fixed points, finite horizon layers, permissive actions, losing ranks, winning strategy certificates and spoiling choices. The controller selects an action, then an adversary selects one of the declared nonempty successors. Controllable predecessor uses an existential action followed by a universal successor condition. Universal predecessor deliberately uses all actions and is recorded separately, avoiding an accidental quantifier reversal. Safe fixed-point closure is finite syntactic evidence in the supplied graph, not measured safety in a physical or social system.

Production uses an iterative descending greatest-fixed-point computation. The independently specified expected values use exhaustive closed subsets and recursive finite horizon predicates under the same owner and infrastructure. That algorithmic difference is useful local checking but is not independent external reproduction. Losing ranks and spoiling choices preserve a selected lower-rank adversarial successor for each losing state/action; outside-safe states start at rank zero. Winning strategy certificates choose a safe action but confer no real controller authority. Every complete envelope and process status was compared, not merely the operation name or output presence. The source tranche and a successful x1 observation were not replayed after the x1 push gate.
