# Book Repair Accessibility

1. Supply structure terms, plain-language summaries, ordered headings, and status messages.
2. Keep colour-independent and nonvisual cues for holds, conflicts, corrections, and outcomes.
3. Include help and manual-evaluation routes without claiming complete accessibility.
4. Reject hidden state, unlabeled status, unsupported conformance, or inaccessible-only evidence.
