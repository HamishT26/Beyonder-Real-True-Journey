# Fragment Custody

1. Assign a phase-local fragment identifier and record the declared source location.
2. Preserve image, enclosure, match-confidence, custody, and correction lineage.
3. Reject silent attachment, disposal, identity conflation, or unsupported certainty.
4. Leave real reunification, ownership, return, and cultural decisions unresolved.

Use `ghc_family_fragment_custody.py` for the v654-v8 deterministic fixture.
