# Adhesive Batch Hold

1. Record the declared adhesive class, source, lot, preparation time, and open-time boundary.
2. Represent viscosity, contamination, temperature, and humidity only with explicit evidence classes.
3. Reject stale, contaminated, untraceable, or authority-promoted fixtures.
4. Perform no mixing, application, environmental action, or real-object release.
