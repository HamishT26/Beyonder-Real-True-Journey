# Forward Difference

Bind values to their index order and divide adjacent increments by a positive declared spacing. It is a one-sided approximation, not an exact derivative claim for arbitrary data.

Use [the paired runner](../../../../../scripts/ghc_family_interpolation_forward_difference.py) with a UTF-8 JSON input file or standard input. The envelope contains exactly `op`, `payload`, and `synthetic: true`; select `forward_difference`. Unknown fields, wrong scalar types, nonfinite JSON, and operations outside the pair are explicit refusals. An output path is opened only as a new file.

The frozen example `NS6896-N031` is in [the phase definitions](../../plan/new-proposals.json). Its independent expected-value basis is: Difference of consecutive squares divided by the declared spacing. Read the full payload and typed result rather than inferring behavior from the title. The evaluator never imports the proposal table.

For a new domain, state grid ordering, units, norm, boundary conditions, resource ceiling, expected result, and a falsifier before execution. Retain a failed subject separately from a passing refusal check. Deactivate this local interface if its assumptions no longer fit; preserve its historical receipts and rollback by removing it from capability selection rather than erasing evidence.

Same-owner finite synthetic software evidence only. This does not establish empirical GMUT confirmation, independent reproduction, production readiness, professional, legal, cultural, affected-party or Maori authority, consciousness, personhood, identity continuity, or Stage 20 readiness.
