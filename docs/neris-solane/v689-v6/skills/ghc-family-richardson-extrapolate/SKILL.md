# Richardson Extrapolate

Eliminate one declared leading error order. The method depends on the supplied order and shared asymptotic regime; it cannot infer those prerequisites from two numbers.

Use [the paired runner](../../../../../scripts/ghc_family_flux_richardson.py) with a UTF-8 JSON input file or standard input. The envelope contains exactly `op`, `payload`, and `synthetic: true`; select `richardson_extrapolate`. Unknown fields, wrong scalar types, nonfinite JSON, and operations outside the pair are explicit refusals. An output path is opened only as a new file.

The frozen example `NS6896-N131` is in [the phase definitions](../../plan/new-proposals.json). Its independent expected-value basis is: Exact Richardson elimination of a leading second-order error term. Read the full payload and typed result rather than inferring behavior from the title. The evaluator never imports the proposal table.

For a new domain, state grid ordering, units, norm, boundary conditions, resource ceiling, expected result, and a falsifier before execution. Retain a failed subject separately from a passing refusal check. Deactivate this local interface if its assumptions no longer fit; preserve its historical receipts and rollback by removing it from capability selection rather than erasing evidence.
