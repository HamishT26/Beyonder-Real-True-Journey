# Module 08 - Packages, environment, and resource use

The three direct additions are Findiff 0.13.1, Numdifftools 0.9.42, and meshio 5.3.5. Their exact PyPI wheels and the eight dependency distributions were frozen in planning. The eleven-wheel closure includes NumPy 2.5.3, SciPy 1.18.1, Rich 15.0.0, Pygments 2.21.0, markdown-it-py 4.2.0, mdurl 0.1.2, SymPy 1.14.0, and mpmath 1.3.0. Every downloaded byte count and SHA-256 matched the official release metadata.

The wheel-only, hash-required installation used a dedicated D-drive target and cache. It installed 4,860 files, built no source distribution, replaced no host interpreter, upgraded no global environment, changed no account or credential, and changed no Windows feature. If the environment becomes unsuitable, its entrypoint can be deactivated while the exact wheel and receipt evidence remains.

A point-in-time OSV query returned no vulnerability identifiers for the eleven exact versions during planning. That result is not exhaustive security or a future guarantee. Package and bundled-binary licensing also remains relevant to redistribution. The wheels and installed environment are evidence resources, not a production deployment or permission to redistribute every dependency.

Findiff reproduced the derivative of a quadratic on ten small uniform grids within the stated tolerance. Numdifftools reproduced ten cubic derivatives within the stated tolerance. meshio wrote and read ten synthetic line meshes in an external D evidence folder, binding each retained file by SHA-256. The ASCII VTK writer emitted its documented debugging warning; the structural round trips passed. No untrusted expression, external mesh, private record, or source-document code was executed.

The phase used two bounded execution sessions and no parallel agent. A package import required one continuation poll rather than a second process. Current materialized and tracked repository counts remain below two thousand. Resource observations on this laptop do not measure model token use, Fast-mode billing, another task's performance, or the preferred settings for a different machine.
