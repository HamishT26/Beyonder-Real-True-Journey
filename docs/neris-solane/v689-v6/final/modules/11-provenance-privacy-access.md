# Module 11 - Provenance, privacy, accessibility, and authority

The provenance operation hashes one canonical JSON representation and compares it with a declared digest. Five examples match and remain represented. Five deliberately mismatch and remain open gaps. The output always denies authority transfer. A digest can help determine whether two readers hold the same bytes; it cannot prove the record's truth, author, consent, ownership, lawful basis, cultural legitimacy, or fitness for a new purpose.

The claim-reservation operation represents five bounded software scopes and retains five broader scopes as exact gates. Physical-law promotion, credential issuance, public policy, Maori authority, and Stage 20 are not executed. A successful reservation record proves only that the interface preserved the gate. It is not an approval of the action described by the gate.

Public artifacts exclude raw task identifiers, private callable routes, user-profile paths, credentials, secrets, private keys, transcripts, screenshots, hidden application state, and real protected participant data. Staged owner-only pattern scans found no candidates across the declared classes. That review is not complete privacy or exhaustive security. Binary PDF content is bound by digest and visual review rather than decoded by a text pattern scanner.

The overview has three deliberately separated pages, black titles, readable type, labelled tables, and a structured HTML companion. The PDF was rasterized after generation and every page is visually inspected for clipping, overlap, missing glyphs, broken tables, and spacing. Manual assistive-technology evaluation remains reserved. A clean render and semantic HTML do not prove complete accessibility for every reader or device.

Freed ID and CBR are project frameworks here, not a live identity system or enacted bill of rights. No real key, proof, issuance, verification, status, revocation, recovery, interoperability, trust governance, or affected-party review occurred. Maori concepts, wording, data governance, and authority remain with competent and affected Maori people and authorities. Silence, possession of data, project enthusiasm, or a local approval packet cannot substitute for that authority.

The four-tier deck organizes one corrigible owner anchor, three pillar cards, four practice cards, and 280 task cards. Parent links support retrieval. They do not create moral hierarchy, personal continuity, consciousness, or measured memory retention.
