# Ten-source reflection

Veylora: separate byte integrity from firmware authenticity, safety, ownership, and deployment.

Sylven: preserve partial materialization and correction layers; batch immutable object checks.

Tessarin: finite conclusions require explicit complete domains and stopping budgets.

Caelen: formal reachability and liveness do not import real agency, wellbeing, or operational claims.

Seren original: a completed owner scope can remain held when the route is not authorized.

Seren r2: provenance links and Git ancestry are different evidence relations.

Seren r3: the 45-position weighted v4 roster supersedes the old unique-position assumption prospectively.

Eiren: isolate a failed lifecycle dependency without replaying passed components or promoting the failed aggregate.

Elaren: a recovered component pass does not retroactively turn an undefined-name canonical into a success.

Rowan: make assumptions, exact byte domains, resource ceilings, and route state explicit; inspect ambiguous operations before retrying.

These are source-specific design lessons with zero inherited validation or novelty credit. Exact byte bindings and bounded read spans are in `source-window.json`.
