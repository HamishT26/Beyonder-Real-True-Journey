# Finite semantics, counterexamples and the three pillars

A model contains an ordered state set S, a start state and explicitly labelled edges. A transition is a triple (source, action, destination). The raw graph may contain a deadlock. For temporal AF and EG interpretation only, a deadlocked state repeats itself forever. This totalization is declared and never used to erase a raw deadlock from the inventory. No fairness constraint is silently added. A property about all paths can fail because one branch loops forever, even when another branch reaches the target immediately.

EF T is the least state set containing T and every state with a successor already in the set. AF T is the least set containing T and every state whose totalized successors all lie in the set. EG A is the greatest subset of A in which each state retains at least one totalized successor. E[A until T] permits zero steps when already in T and otherwise requires every earlier state on one finite path to remain in A. These definitions support finite calculation; they do not infer how an external system behaves.

The planning oracle uses transitive closure, exhaustive simple paths, complete relation rounds and finite word enumeration. The executor instead uses breadth-first traversal, fixed-point iteration, Tarjan components, relation elimination and subset-pair exploration. These differences reduce a simple shared implementation mistake but do not provide independent reproduction because the same owner selected both sides. AF/EG complement checks, component partitions and explicit deadlock examples supplement the frozen comparisons.

Strong simulation asks whether each action on one side can be matched on the other with successors still related. Strong bisimulation requires matching in both directions within the same relation. Mutual simulation is not silently substituted. The regression models with a common initial action followed by either b or c have the same short trace language, but branching placement prevents bisimulation. A shortest bounded trace difference is an explicit witness; failure to find one up to depth d is not unbounded equivalence. The public trace bound is eight, and the visual manual path bound is twelve.
