Conventions that matter
A twist toggles membership of a declared subset in every feasible set. Symmetric exchange allows the same element to be selected twice: its set contains that element once, so it toggles once. Uniform parity can mean all feasible sets have odd size. Loops and coloops use the explicitly declared minor conventions.
The nullity-distance view compares two computations of the same finite quantity. Their agreement is same-owner software evidence. Real observations, participant interpretation, human accessibility review and consequential authority remain open.
