Infrastructure does a different job

Docker packages the workload. Kubernetes schedules it and may replace workers. Nexus mediates reviewed actions. The Sentinel design connects a selected model, private records and bounded tools. Each boundary still needs its own evidence.

Recovery needs a coherent set

Three valid files from generations 7, 7 and 8 do not form one generation-7 checkpoint. In this model, recovery stays held until the intended complete set is identified. A matching file hash alone does not supply authority.

Scope, sources and reproducibility

The scenarios below are deliberately small and finite. They illustrate proposed workflow decisions. They do not implement authentication, an execution supervisor, durable storage, remote cancellation or exactly-once effects.

  • Kubernetes Job documentation warns that a program may sometimes start twice even with one completion, one parallel worker and restartPolicy Never. A scheduler is not an application-level deduplication guarantee.
  • Docker resource constraints explains explicit memory and CPU limits.
  • Scenario ledger and manual review steps describes every terminal state and the evidence ceiling.
  • Infrastructure status and NZ pilot proposal separates current source evidence from future work.
