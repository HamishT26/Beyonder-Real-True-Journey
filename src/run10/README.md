# Reviewed identity and governance models

This package contains the corrected identity laboratory, the finite governance model, their composition adapter and the original synthetic case inputs. The recorded composition run matched12 of12 literal expectations. Preparation labels in fixtures are historical; VALIDATION.json describes the later observation.

These models grant no real permissions. Human proofs are invented fixtures, and six ephemeral keys generated by one harness do not establish six independent identities. A production adapter would need protected enrollment, human-origin verification, fresh revocation checks and durable operation state.

Source contributions: Merrin and Orenna; separate source/receipt review by Avelin. Tests were run on Windows with Node26.11.1. The full local execution journal is retained in the owner evidence bank; this public selection contains no private controls, credentials or machine paths.
