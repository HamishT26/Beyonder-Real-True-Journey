# GHC App and chat recovery

Use menu 7 in the GHC Nexus Hub for the preserved chat catalogue. Choose I for offline IDs and routes, P for the official local CLI resume picker, or F to filter by title or exact ID. Saved status is historical. Cloud and ChatGPT records keep their original provider; a UUID alone is not a transcript or a grant.

## Windows entrypoints

- GHC Codex - Registered App: the normal Windows registered app entry.
- GHC Codex - Administrator: direct launch of the signed current package executable using normal Windows Administrator consent. The 7 October restart measured an elevated command executor and Codex processes. Direct App processes had no Windows package identity; use the separate registered App entry for updates.
- GHC Nexus Hub - Administrator: elevated local terminals and the same menu.
- GHC Nexus Hub - Current User: the same menu using the current Windows token.
- GHC Nexus Hub CMD - Administrator / Current User: the same Node Hub through Command Prompt, with the corresponding Windows token. Changing the integrated terminal shell does not change the agent environment or grant cloud privileges.

The official local CLI picker is unavailable from the Hub while a saved same-host local record is explicitly held, because the picker cannot filter those Hub holds. Select an exact unheld chat instead. Provider locks remain authoritative at resume time.

The App launcher requires the existing App to be closed after saving work. It never kills the App or changes the signed OpenAI package. An accepted launch is not proof of identity, elevation or server access; verify those in the reopened session.

## If a cloud chat shows HTTP 403

Record the exact error and time. Check the same account and workspace on another official client. Preserve the original ID and execution host. Relaunch the registered desktop app once after saving work. If the same refusal persists, use the official account sign-in controls or OpenAI support; do not delete session databases, remove locks, recreate the chat, alter the package manifest or copy another client credential.

The Hub cannot grant cloud access that the provider refuses. Its read-only recovery catalogue remains useful during the outage. The private D-drive recovery bank contains the detailed known IDs and diagnostics. Keep that bank private.

## Rollback

The installation receipt names a D-drive backup with hashes for every replaced runtime file and shortcut. A rollback should restore only the recorded targets after verifying backup hashes, preserve files added by later work, and leave private identities, memories, sessions and credentials untouched. The previous launcher is backed up independently. Normal registered launch remains available if the Administrator route cannot be verified.
