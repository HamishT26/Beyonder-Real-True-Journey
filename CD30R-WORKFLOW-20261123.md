## Evidence model

Keep these units distinct:

1. A proposed project and its acceptance criteria.
2. A prepared source, document, fixture or experiment.
3. An actual execution with its environment, bounds and output.
4. A producer's interpretation of that output.
5. An independent source review.
6. An independent reproduction.
7. A scoped acceptance decision.

A delivered message is not recipient acknowledgement. A created document is not an executed project. A synthetic passing case is not production readiness. A source review cannot establish a runtime property by itself. An inherited result receives no new completion credit.
