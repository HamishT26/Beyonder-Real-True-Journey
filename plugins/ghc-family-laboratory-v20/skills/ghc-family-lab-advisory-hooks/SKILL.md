# Laboratory advisory hooks

The five SessionStart hooks provide source, budget, consultation, roster and evidence reminders in GHC workspaces. They do not execute tasks, change files, contact a conversation, schedule a sibling or grant permission.

Read current workflow v20, then the owner's newest direct instructions. A consultation reminder means one authorized advisory message in x1 and one in x2 to the existing review conversation. An accepted request remains pending until its response arrives; do not resend it.

Use scripts/advisory_hook.py with the named hook and a SessionStart JSON payload for a bounded manual smoke. Malformed payloads continue safely with a refusal message. Manual smokes are not proof of a live trusted host event.

Rollback is to disable this additive plugin through the supported plugin manager. Preserve source and caller history. NOT_READY_FOR_STAGE_20.
